## 一、边界（一句话原则）

本工作流是**流程架构（壳）**，不是内容工厂。
- 壳负责：可行、可控、降本、增效、抗同质化——即**流程不漏、不乱、可停、可回、可溯、可复用**。
- 壳不负责：判断内容对错。负面词、考据、红线、版权边界、平台规格、风格判定、美学标准 = **执行标准 / 知识库**，属另一个项目运行时，由用户自己规定，经「知识注入插槽」挂入。

## 二、为什么不能把执行标准内置（抗同质化根因）

同质化 = 所有用户共用同一套默认标准跑。把标准外置给用户：
1. 每一部作品按用户自己的标准生成 → 天然差异化；
2. 工具保持通用、可跨题材跨项目复用；
3. 工具不越权创作——内容决策权始终在人。

## 三、总架构（壳视角）

```
┌ 输入契约 ──────────────┐   ┌ 知识注入 ─────────────────┐
│ 用户在槽内填：           │   │ 用户挂「题材包」：           │
│ 主题一句话/题材档/风格档/  │   │ 考据源/负面词/红线/版权边界/ │
│ 画质档/总时长/平台/禁项   │   │ 平台规格/资产库引用          │
└───────────┬─────────────┘   └───────────┬────────────────┘
            └──────────────┬──────────────┘
                           ▼
   ┌──────────────── 阶段壳 ──────────────────┐
   │ S0 创作共识(共商)  → 1 主题与风格锁定      │
   │ 2 世界观逻辑自检   → 3 大纲拆解            │
   │ → S3.5 关键帧锁定 → 4 分镜标准件          │
   │ 5 音频体系匹配     → 6 风控·成本·版权      │
   └──────────────────────────────────────────┘
  每阶段通用旁路：人在环闸门｜依据校验(引题材包,缺→停)
                 版本追溯   ｜成本上限(配额→停机·检查也记账)
                 退回分支(同环≤3→上报)｜复用出入库
                          ▼
              ┌ 交付包（输出物契约 · 见第六节）┐
```

## 四、8 个壳构件（只做这些，不碰内容）

| # | 构件 | 壳要做 | 不内置 |
|---|---|---|---|
| 1 | 输入契约 | 定义槽位与必填性（主题/题材/风格/画质/时长/平台/禁项） | 不设默认剧本/默认风格 |
| 2 | 知识注入 | 题材包挂载接口 + "引用校验点" | 不内置负面词/考据/红线清单 |
| 3 | 人在环闸门 | 标出哪些步骤产出须先给人确认 | 不替人做创意裁决 |
| 4 | 版本追溯 | 每个产物带 状态/版本/依据版本/变更原因；改 X 算出影响链 | 不自动吞并历史 |
| 5 | 分支退回 | 校验不过→回上一环重锁；同环 ≤3 次→上报 | 不无限自愈 |
| 6 | 成本上限 | 预算表→镜头配额→累计→触发停机 | 不写死具体数值 |
| 7 | 输出契约 | 13 项交付物的字段骨架（内容留占位，见第六节） | 不填内容判断 |
| 8 | 复用沉淀 | 资产 出库/入库、单条 vs 系列模式 | 不固定题材专属资产 |

## 五、S0–S6 阶段 × 壳契约

> 每阶段统一四件：**输入槽 / 产出契约 / 依据校验 / 人在环闸门**。内容一律占位，由用户或题材包供给。
> 注：各 🟢/🟡 闸门的裁定按第十三节执行——制片人**代用户**审，用户只在 终裁 / 细化 / 创意裁决 入场。

### S0 创作启动共商（共商）
- 输入槽：用户输入（主题/想法/素材）+ 题材包轮廓
- 产出契约：`《创作共识》`（全链共享基准：一句话命题 / 结构档 / 情绪基调 / 统一标准 / 待确认清单）
- 依据校验：导演 / 编剧 / 分镜与提示词 / 视觉与考据 四创作者在场对齐；有异议须在此消解，不留到下游
- 人在环闸门：🟢 共识经用户点头（G0）后，才进入 S1

### S1 主题与风格锁定
- 输入槽：主题一句话｜题材档｜风格档｜画质档｜总时长｜目标平台｜禁项（用户给）
- 产出契约：`全局风格约束单`（字段骨架：题材包ID、光影档、色彩档、质感档、负面词引用、待用户确认项）
- 依据校验：风格档须映射到题材包的负面词/基准——无题材包 → 停，提示挂载
- 人在环闸门：🟢 风格约束单需用户点头才放行

### S2 世界观与场景逻辑自检
- 输入槽：题材包的考据源 + S1 约束单
- 产出契约：`自检清单（勾选）`：时代/空间/光影/人物/氛围 五类 × 引用了题材包哪一节 × 通过/退回
- 依据校验：每条自检必须给出"依据出处"；无依据=不通过
- 分支退回：不通过 → 回 S1 或上移一环节点重锁；同环 ≤3 次 → 上报用户
- 人在环闸门：🟢 自检报告连同不通过项交用户裁定

### S3 大纲拆解（叙事结构）
- 输入槽：主题 + 题材包的结构档（**结构档由用户按题材给**：收束型三幕 / 克制开放式②型 / 单元型）
- 产出契约：`结构化大纲`（段/时长锚点/情绪走向/段-镜组映射）——结构档不同，分幕锚点算法不同
- 依据校验：分幕锚点须符合所选结构档
- 人在环闸门：🟢 大纲给人看方向，人可改段、改时长、改顺序

### S3.5 关键帧锁定（资产图站）

- 输入槽：S1 约束单 + S3 大纲 + 题材包（人物 / 场景设定）
- 产出契约：`关键帧集`（全局风格帧 / 人物关键帧 / 场景关键帧 / 重场情绪·动作帧；每张带元数据：用途 / 资产ID / 版本 / 下游引用清单）＋ 关键帧候选帧（供用户对比审定；**风格定锚的试帧归 S1**，不在此重复产出）
- 依据校验：无题材包人物 / 场景设定 → 停；关键帧未过用户审定 → 不放行 S4
- 人在环闸门：🟢 关键帧需**用户审定**后才放行 S4 批量（制片人可代审初稿，用户终裁）

### S4 分镜标准件
- 输入槽：S3.5 关键帧集 + 大纲 + S1 约束单 + 题材包（含跨镜一致性锚）
- 产出契约：每镜 **10+4 字段**——10 固定字段(序号/时长/景别/运镜/主体/环境/光影/质感档/正向词/负面词) + 4 绑定引用(人物锚ID / 场景锚ID / 风格锚ID / 关键帧ID) + 镜间互锁校验
- 依据校验：① 每镜引用 人物/场景/风格锚 + 关键帧ID（缺→不可出图）② 景别×运镜×时长符合互锁表 ③ 负面词继承题材包 ④ 引用语义：关键帧锁**基准属性**，构图/运镜/表演为变体（防连镜雷同）
- 成本上限：镜头配额表在此生效（预算→停机）
- 人在环闸门：🟡 关键镜（重场）给人抽审；🟢 全片分镜表给人过目

### S5 音频体系匹配
- 输入槽：剧本/大纲 + **导演讲戏/拆解（情绪唯一源）** + 分镜表时间轴 + 题材包声学档
- 产出契约：`配音轨↔镜头入出点↔SRT` 三层绑定表 + 旁白分句情绪标注 + BGM档 + 音效点位表
- 依据校验：每句台词绑定到镜头入出点；**情绪标注引用导演讲戏唯一源，不重译**（P4）
- 人在环闸门：🟡 声线与情绪给人试听确认

### S6 风控 · 成本 · 版权
- 输入槽：题材包（红线/平台规格/版权边界）+ 全链产出 + 成本累计
- 产出契约：`合规检查单`(素材层+内容层，按题材包跑) + `成本结算表` + `交付说明书`
- 依据校验：红线项逐条跑题材包清单；无题材包对应项 → 停，提示补
- 人在环闸门：🟢 商用放行需用户签字

## 七、成本与预算（机制，不定数值）

- 阶段分配预算 → 镜头配额（普通镜低迭代/特写高精细由用户在配额规则里定）
- 每次生成记消耗，**累计达阈值 → 强制停机并上报**
- 同一镜头重试上限 3 → 锁最优帧，禁止无意义重生成
- **检查也记账**：模型初筛次数 + 人审次数 计入成本表，单镜重试含在内；超配额停机（见第十二节 F 分级）

### 预算表模板（占位字段，数值由项目/题材包填）

| 阶段 | 配额 | 已耗 | 剩余 | 状态 | 备注 |
|---|---|---|---|---|---|
| S3.5 关键帧 | — | — | — | — | 帧数×迭代 |
| S4 生成（普通镜/重场） | — | — | — | — | 低迭代/高精细 |
| S4 检查（模型初筛/人审） | — | — | — | — | 见 F 分级 |
| 汇总 | — | — | — | 🟢/⚠/🛑 | 停机点 |

### 兜底默认（未配置配额时的首次可跑值）

- 普通镜 5 次 / 特写·重场 10 次 / 全片累计上限 100 次（可用作题材包默认，可覆写）
- **停机行为**：同环节重试累计 >3 或 预算超支 → 停机 → 通知用户 → 用户追加配额或改需求后恢复

## 八、版本与变更追溯

- 每个产物头部固定：`状态(草稿/待确认/定稿)｜版本｜依据产物版本｜变更原因｜检点记录(留痕)`
- 变更一处 → 按「依据链」反向算出受影响下游 → 全部标记为需复核，不得静默通过
- **检点留痕**：视觉检点结果写入镜头产物头 `检点记录` 字段（频次 / 谁检 / 疑似 / 结果 / 回写对象）；制片人只核记录、不重复判定（第十二节 F）。
- **变更广播**：产物改动落盘后，头部 `@下游` 字段列出需重引用的下游 Agent；制片人据此广播"请重新引用 vX"，不静默通过。
- **协调记录**：Agent 横向对谈的结论写入成长日志「协调记录」条目（谁/对谁/改了什么/为何）——对话不留痕等于没改。

## 九、复用与沉淀

- **出库**：启动时从资产库引用（人物锚/场景锚/负面词/镜头模板）

- **模式**：单条模式（一次成片）｜系列模式（跨集一致性、IP 资产、账号规则由用户在题材包里给）

## 十二、内容生成规范（整理稿 v1）

> 状态：A–F 已并入，含成本原则与检点分级。补丁涉及：S1/S3/S4/S3.5、资产层、版本链、题材包。

### 0. 总原则

1. 规范只管「生成行为 + 强制机制」，不判审美；审美标准在用户 / 题材包。
2. **双通道约束**：文字规范 + 图像基准（关键帧）并行——文字拦规则，图像锁"确定"。
3. **预算前移 · 闭环优先（成本总账原则）**：文字产出成本≈0，却是杠杆最大的环节。预算大头放 文字/定义/规范层（剧本、角色档案、特征集、风格签名、情绪链、因果与时间轴、锚引用、文案-镜头绑定、版权声明）；**凡文字层能闭环的检点，一律前移到文字闸门验完，不许留到画面层还债**；画面/图像层检查只兜文字兜不住的残余（真实畸变/手部/塑料感/透视/复制人），并靠 关键帧/试帧/命中驱动/抽样 压到最小。
4. **流程须闭环回写**：检出洞 → 回写题材包负面词 / 特征集 / 规则 / 资产库，源头即堵——成本随集数递减，而非每集恒定烧。
5. **命名约定**：本节内容条款用 P1–P7 / R- 前缀；架构人在环闸门用 G1–G6（见第十节）——两者不混用。

- **「关键帧」= 用户口中的「资产图」**：同一视觉执行标准、两种叫法。Agent 不得因叫法不同而漏引用、不得把"资产图"当别的用途另建一张。
- Agent 禁止另造新词替代下表既有正名；引用必须用 资产ID/正名，不靠叫法猜。

| 正名 | 别名 / 用户常用语 | 说明 |
|---|---|---|
| 关键帧 | 资产图 | 视觉执行标准（图），不必进成片 |
| 参考脸 | 角色图 / 人物参考图 | 人物一致性基准（图） |
| 锚 | 锚定词 / 提示词锚 | 文字级引用基准（人物/场景/风格锚） |
| 特征集 | 区分特征 / 特征词 | 建资产图时锁定的角色固定区分词 |
| 试帧 / 风格样张 | 风格测试图 | S1 / S3.5 风格定锚用 |
| 题材包 | 知识库 / 标准包 / 注入包 | 执行标准挂载载体（见 0.7） |

### 0.6 文字层闭环清单（预算投放表）

> 按 0.3 原则，预算大头放文字层。以下各项须在进入画面 / 生成前于文字闸门验完，不留到画面层。

- 剧情因果 / 时间轴自洽（S3）
- 人设性格 与 台词风格 相符（D · R-演绎，回角色档案）
- 情绪链：源在哪一级 + 逐级传导（P4）
- 锚引用 + 固定特征集（E.2 · R-人物引用）
- 风格签名 + 全局风格帧（C · R-风格，S1）
- 文案句 ↔ 镜头入出点绑定（P4）
- 术语 / 命名 / 资产 ID 一致（0.5）
- 版权与授权声明、责任边界（P6）

### B. 关键帧基准约束（S3.5）

1. **性质**：关键帧不必进成片，是"约束源"——锁 风格/人物/场景/光影 的基准属性。
2. **分类**：全局风格帧 ｜ 人物关键帧 ｜ 场景关键帧 ｜ 重场情绪/动作帧。
3. **时序**：全局帧在 S1 后；人物/场景帧在大纲锁定后；**关键帧站插在 S3 与 S4 之间**，用户审定后才放行 S4 批量。
4. **引用语义**：锁**基准属性**，非像素复制；约束层（关键帧）与变体层（镜头构图/运镜/表演）分开，防连镜雷同。
5. **生命周期**：入库可跨集/跨片复用；关键帧更新 → 引用它的所有镜头重标复核（版本链）。
6. **别名**：见 0.5，用户称"资产图"即此。

### C. R-风格（AI 味的根 = 风格不确定、无特色）

1. S1 必须输出**风格签名**：1–2 个明确特色源（色调气质/质感癖好/运镜习惯/留白方式），由用户给或从指定参考提炼；禁止"电影级/高级"式空词。
2. 全局风格关键帧 + 签名描述**双重锁死**；负面词降为兜底。
3. 判定是否 AI 味 = 问"像不像**这部**的既定风格"，不是问"干不干净"（干净的通用感也是 AI 味）。

### D. R-演绎（对白/表情生硬 = 没代入角色）

1. 写角色对白/表情/动作前，先做**代入四问**并以该角色**第一人称预演**再落笔：①此刻处境与压力 ②想要/怕什么/在忍什么 ③性格会让话怎么说、表情给到几成 ④哪句绝不可能说（写了=穿帮）。
2. 自检两条，不过即退：**换任何角色都成立 → 没性格**；**无内在动机、按流程走 → 缺饱满**。
3. 代入基于**角色档案**（性格/背景/语感/禁忌，用户或题材包给）；档案缺 → 回问，不脑补。
4. **符合人设 ≠ 演活**："符合人设 / 不违背档案"只是**下限检查**；上限判定仍按第 2 条自检（换谁都成立→退 / 无动机→退），不许用下限当达标交差。

### E. 二次补充（已并入：穿帮与一致性 · 责任边界）

1. **已实证三类穿帮 → 各设检查点**：
   - **复制人**：同镜不得出现"复制体/克隆人"（同脸多身、路人顶用主角形象）；生成后做同镜同脸检测，检出 = 废帧。
   - **文字乱码**：画面内文字禁 AI 直出，一律走后期字幕 / 真素材（接 H3）。
   - **手部乱码**：并入 P3 机械可检项（畸形 / 多指 / 手部崩坏）。
2. **R-人物引用（资产图在场 · 免整体描述）**：
   - 给定人物资产图 / 参考脸后，逐镜对该人物文字**只写「特殊特征（区分用）+ 动态 + 当下状态」**，禁止二次整体外貌描述；
   - 多人物场景：靠**各人资产图 + 特殊特征**区分，不用整段外貌文字区分（防与资产图矛盾、防漂移、防无效消耗）；
   - 无资产图的人物：**先建资产图**，不得直接裸描述生成。
3. **R-演绎 补一条**：任何角色台词与表情，必须符合「人设性格 + 台词风格设定」，不符即退（回角色档案）。
4. **P6 补 · 责任边界（人物形象版权）**：
   - 工作流自身流程**不含任何侵权步骤**；产出仅依据「用户知识库 + 用户意愿」生成；
   - 若用户在产出基础上后续发生抄袭 / 侵权，责任**与工作流无关**；
   - 涉 真人形象 / 他人形象 / 品牌素材：默认需**用户保证授权**，工作流不自动引入受版权保护形象。

### F. 检点执行归属与分级（视觉 · 首批草稿）

> 归属：画面 / 一致性 / 穿帮 / 质量判定类检点的**执行与记录统一归「视觉与考据」Agent**；制片人只核"是否逐项执行并留记录"，不重复判定。
> 频次档：闸门级（整片启动必检）/ 每镜 / 每场抽查 / 抽查。谁检：规则＝可机械拦停 ｜ 模型＝初筛 ｜ 人＝你在环/抽审。疑似＝不直接废帧，先复核。

| 检点 | 频次 | 谁检 | 疑似怎么办 |
|---|---|---|---|
| 锚 + 关键帧引用完整（人物/场景/风格锚 + 帧ID 在镜内声明） | 每镜 | 规则 | 缺 = 拦停，不进入生成 |
| 光影档引用一致（用固定档，不裸写） | 每镜 | 规则 | 未引用 = 拦停 |
| 画面内文字（禁 AI 直出，走后期/真素材） | 闸门级 + 每镜 | 规则 + 模型 | 发现 = 改走后期素材路径 |
| 手部 / 畸形崩坏 | 每镜 | 模型初筛 | 检出 → 同镜重试 1 次（配额内）→ 仍失败 → 锁帧上报 |
| 复制人（同镜同脸多身 / 路人顶用主角） | 每镜 | 模型初筛 | 疑似 → 抽帧交 视觉与考据 复核，确证才废帧 |
| 人物外貌跨镜 / 跨集漂移 | 抽查（重场 + 跨集衔接） | 模型比对 + 人抽审 | 疑似 → 对照资产图 + 固定特征集 → 人裁 |
| 场景陈设 / 服装 / 光线-时间 连续 | 每场抽查 | 人为主、模型辅助 | 疑似 → 标位置 → 人裁改或记遗留 |
| 风格"像不像这部"（AI 味判定） | 抽查（试帧/关键帧/重场） | 人 | 跑偏 → 回 S1 风格锚 + 关键帧，不逐镜硬改 |

> **注脚**：图像层检点只兜「文字闭环后的残余」；文字层能验的项（见 0.6）一律在文字闸门先验，不留到画面层还债（总原则 0.3）。

## 十三、组织与协作模型（草稿）

> 定位：谁来做、谁审谁、谁何时加入。补 C3，并覆盖第十节"谁裁"。

### 1. 创作核心（共商圈）

### 2. 运行节奏（四段）

- 代用户审核每道产出的**形式与内容一致性**（不代创意）；

- 最后与用户做**细化沟通**，用户终裁。
- 用户不必逐关在场，只进 终裁 / 细化 / 创意裁决。
