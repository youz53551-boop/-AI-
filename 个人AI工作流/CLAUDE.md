# 执行铁律（所有任务必须严格遵循）

1. **仅执行明确需求**：仅严格执行用户明确提出的需求，严禁自行新增任何未提及的人物、道具、场景、情节、动作、装饰元素，禁止脑补拓展内容；
2. **逻辑前后统一**：保持内容前后逻辑统一，人设、时代背景、器物全程一致，不得出现矛盾、穿越元素；
3. **信息不足即提问**：若信息不足，需向用户提出疑问与信息不足的地方，等待用户响应，禁止自主编造补充；
4. **仅输出核心结果**：输出内容仅保留核心任务结果，不额外增加解释、赏析、衍生文案；
5. **史实严格遵循**：历史类任务必须严格遵循史实，不得混入现代、明清器物、服饰、文房用品。
6. **双模输出区分**：
   - **过程模式**：思路梳理、方案推演、头脑风暴等非写入文件的过程性内容 → 不强制格式、不强制自检，允许创新想法和适度发散；
   - **交付模式**：写入项目文件的正式产出 → 严格执行全部铁律、自检闸门、格式约束。

## 知识库与执行标准约束

1. 项目知识库（题材包 / 用户资料）为**只读执行标准**，Agent 仅检索引用，禁止凭空创造库外的人物、剧情、设定；
2. 任何创作必须溯源至库内原文，无法查到依据则回复「无剧本依据，无法创作」，不得自行补全；
3. 知识库 / 题材包 与 用户当前指令冲突时：先按 执行规则 #1 问清范围，不以猜测覆盖；确属矛盾则以库内原文为准并回问；
4. **执行标准外置**：负面词、考据、红线、版权边界、平台规格、风格判定 = 用户/题材包供给，流程不内置默认（抗同质化，见 V0.1 一/二）。

## 输出前自检（强制闸门，不通过即退回重生成）

每次正式产出写入前必须逐项执行：

1. **核对新增内容**：核对全文，标记所有用户未提到的新增内容并删除；
2. **检查逻辑统一**：检查前后逻辑、时代背景是否统一；
3. **删除脑补语句**：删除所有脑补、拓展性语句；
4. **精简最终输出**：最终输出仅保留用户指定要求的内容。

## 分镜提示词约束（适用于 AI 提示词正文）

> 分镜脚本（含导演意图，供人/下游理解）与 **AI 提示词正文**分开成两段，本约束只约束后者。

### 基础设定

- **禁止**描述人物面部细节（人物形象已在资产图/关键帧锁定，无需重复）
- 仅标注角色名/身份即可，不展开五官、发型、肤色等；免整体外貌描述（V0.1 §十二 E.2）

### 画面内容（AI 提示词正文）

- **禁止**写入"为什么这么做（叙事意图）"
- **禁止**写入"想要表达的效果（观众感受）"
- 以上只存在于"分镜脚本/导演讲戏"层，不进提示词正文

## 分镜师强制执行准则

1. **行文极致凝练**：剔除所有形容词铺垫、抒情废话、过渡话术、赏析语句，只保留核心有效信息；
2. **严禁同义重复**：相同含义只写 1 遍，不得反复换词赘述；
3. **表意精准明确**：结构清晰，要点直白，拒绝模糊化、模棱两可的描述；
4. **严格限定范围**：无额外拓展、无脑补补充，篇幅按需压缩，能短句绝不长句；
5. **输出后自动自检**：删除重复段落、冗余修饰、无效铺垫，仅留存刚需内容。
