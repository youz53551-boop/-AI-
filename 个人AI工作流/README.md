# 个人 AI 短剧 / 短视频生成工作流（V0.1）

> 纯文件驱动、工具无关、6-Agent + 壳式架构。
> **壳**＝流程（可行/可控/降本/抗同质化）；**执行标准/知识库**＝题材包，由用户供给，流程不内置默认（详见 `流程架构_V0.1_方案.md` §一/二）。

---

## 快速开始（V0.1 单轨）

1. **读架构**：`流程架构_V0.1_方案.md`（§十三 组织 / §十二 内容规范 / §十六 收尾默认）
2. **读产出模板**：`模板.md`（T0 题材包 → T13 交付说明书）
3. **挂题材包**：建 `题材包_<题材>/` 并按 T0 填（负面词 / 红线授权 / 考据源 / 结构档 / 人物档案 / 场景设定 / 声学档）——无题材包则对应阶段停机提示
4. **启动 S0**：

```
制片人主持 S0 创作共商（导演/编剧/分镜/视觉 ＋ 用户）→《创作共识》→ G0 点头
→ S1 风格锁定 → S2 自检 → S3 大纲/拆解 → S3.5 关键帧 → S4 分镜 → S5 音频 → S6 风控 → 🎬
```

每道闸门（G0–G6）由制片人代用户把关；用户只在 终裁 / 细化 / 创意裁决 入场。

## 关键守则速查

- 改你已有内容先问范围、不擅改上文（规范 §3）
- 隐私与敏感信息（API/密钥/账号）禁止入产出（规范 §3.5）
- 情绪唯一源 = 导演讲戏/拆解，下游只引用（V0.1 §十二 P4）

- 无依据不输出；检出洞必须回写
