# 产出模板（V0.1 版）

> 按 `流程架构_V0.1_方案.md` §六 输出物清单组织；内容一律占位，由用户 / 题材包注入。旧模板（导演执行计划/全本剧本等）已整篇合并移除。
> 通用产物头：`状态(草稿/待确认/定稿)｜版本｜依据产物版本｜变更原因｜检点记录｜@下游`

# T0 · 题材包

```
题材包_<题材>/
├─ 00_ID.md           题材ID｜适用项目｜版本
├─ 负面词基础表.md     绘图/生图 ＋ 文案
├─ 红线与授权.md       内容红线/真人肖像/品牌地标/平台规格/版权·声学边界
├─ 结构档·情绪档.md    档位(①/②/③)｜情绪标签集｜声学档
├─ 人物档案.md         角色：性格/背景/语感/禁忌/固定特征集/参考底图
├─ 场景设定.md         场景清单＋参考底图/关键帧引用
├─ 考据源.md           历史或现代生活逻辑依据
└─ 版本.md             变更记录
```
