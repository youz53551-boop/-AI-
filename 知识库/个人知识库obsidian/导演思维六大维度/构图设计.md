## 构图设计

### 新增知识点：轴线规则（180 度规则）

#### 核心公式
**180 度轴线 + 不越轴拍摄 = 观众不会迷失方向**

#### 你的观察
> 人物之间形成一条轴线，拍摄时画面的切换只能是在同一轴拍摄的画面。

#### 扩展知识
这是 **180 度规则**（180-Degree Rule）。在两个角色对话时，他们之间形成一条无形的"轴线"，摄像机只能在这条轴线的一侧（180 度范围内）拍摄。如果摄像机越过轴线到另一侧，观众会感觉"角色突然交换了位置"——空间关系被打破。

#### 轴线规则图解

```
         [角色 A] —————— 轴线 —————— [角色 B]
              \                           /
               \         摄像机          /
                \        (180°)         /
                 \                     /
                  \                   /
                   \                 /
                    \               /
                     \             /
                      \           /
                       \         /
                        \       /
                         \     /
                          \   /
                           \ /
                            V
                      [越轴拍摄 ❌]
```

#### 越轴的例外

| 例外情况 | 说明 |
|---------|------|
| **移动镜头** | 摄像机在运动中越过轴线，观众能"看到"越轴过程 |
| **中性镜头** | 插入一个在轴线上拍摄的镜头（正对角色），重置空间感 |
| **空镜插入** | 插入一个与对话无关的空镜，让观众"忘记"当前的空间关系 |
| **刻意越轴** | 制造混乱感/不安感（如争吵、冲突场景） |

#### 🛠 应用模板
```
场景：两人对话
轴线设计：
  1. 建立轴线：第一个镜头展示 A 和 B 的空间关系（全景）
  2. 保持轴线：所有正反打都在轴线同一侧拍摄
  3. 如果需要越轴：先插入一个中性镜头（正对 A 或 B），再切到轴线另一侧
```

## 主学：构图设计 · 画框本身就是叙事

### 两个主关键词：黄金分割 + 极致留白

---

### 构图 · 知识点 1：黄金分割 · 人物不居中，偏左或偏右

**我的观察**：大多数是黄金分割法，人物不是居中，大多偏左或者偏右。

**📚 知识点补强 · 构图理论**

你看到的"不居中"在业内叫 **三分法构图（Rule of Thirds）**。业内把"把画面横竖各分三等分，主体落在四条线交点"这种构图叫 "Rule of Thirds"（三分法构图）。

《白日梦想家》用的是三分法的"变体"——业内叫 **"dynamic thirds"（动态三分法）**，人物既落在三分线上，但同时配合其他元素（百叶窗 / 窗框 / 桌沿）形成"次级框架"。

|构图类型|画面感|本片对应|
|---|---|---|
|居中构图|"被展示的主角"|极少（仅在开篇 eHarmony 一瞬用过）|
|三分法|"存在于世界的普通人"|本片主用|
|黄金分割（螺旋）|"画面的'呼吸'"|大场景用（如喜马拉雅）|
|框架式构图|"被关在框里"|前期公司 / 公寓用|
|留白构图|"渺小但自由"|冒险段用|
|对称构图|"理想 / 神圣 / 完满"|Sean + Walter 雪山剪影|

**为什么"不居中"显得高级？**  
因为人眼在看电影时，自然会被三分点吸引（这是格式塔心理学原理）——把主角放在三分点，画面看起来"自然"；把主角放在正中，画面看起来"刻意"（MV / 官方照常用）。

业内有一句行话：**"居中 = 演员；三分 = 角色；留白 = 人"**。《白日梦想家》用三分，是不要 Walter 像"演员"，要他像"人"。

> 💡 **关键词**：Rule of Thirds / dynamic thirds / 框架式构图 / 留白构图 / 格式塔心理学

### 构图 · 知识点 2：极致留白 · 大场景的"渺小但自由"

**我的观察**：在一些大场景中采用极致留白的构图……他已经被宏大的世界稀释了个人渺小的痛苦……镜头仿佛在说，看，世界如此宏大，不要再困于个人的世界中了。

**📚 知识点补强 · 景别学**

你观察到的"人变小"在业内叫 **极远景（Extreme Long Shot）**。业内按"人物占画面比例"分景别：

|景别|人物占比|业内功能|本片对应|
|---|---|---|---|
|特写 Close-up|70%+|强调情绪 / 困在框内|前期公寓 / 通勤|
|中景 Medium|30-50%|日常 / 对话|公司 / 与谢德对话|
|全景 Long|5-15%|展示空间|街头 / 港口|
|极远景 XLS|1-5%|渺小 / 自由 / 史诗|本片主用（冒险段）|
|大远景 EWS|<1%|天地 / 神性 / 仪式感|Sean + Walter 雪山剪影|

你的观察"人变小=心变大"，在业内叫 **"sublimation through scale"（通过景别实现升华）**。这是电影语法里最常用的"心理外化"手段之一——

**为什么"小"反而让人觉得"自由"？**  
反直觉吧？其实是因为：当人物"小"到画框装不下时，观众潜意识会觉得"他不再被画框限制"。业内把这种设计叫 **"breakthrough the frame"（突破画框）**——表面是"人小"，实际是"画框不再是他的边界"。

**对比设计**：

- 诺兰《星际穿越》用极远景 = 宇宙之小、人类之渺
- 维伦纽瓦《降临》用极远景 = 外星人之大、人间之小
- 本·斯蒂勒《白日梦想家》用极远景 = 世界之大、自我之小，但"小"是"放下了"

同样是"人小"，每部片说的事不一样。

> 💡 **关键词**：Extreme Long Shot / sublimation through scale / breakthrough the frame / 心理外化

### 维度一：构图设计

**核心洞察：** 这份材料将构图从“几何规则”升级为“视线引导系统”，并创造性地将“物质层的前景”纳入了构图设计的范畴，形成了“几何层 + 物质层”的双层构图体系。

**详细分析：**

1.  **几何层：7种视线落点规则**
    *   材料引用了Xuan酱的7种构图（中心、对称、三分法、对角线、引导线、框架式、前景构图），并将其定义为“几何层”。这7种构图的核心功能是<mark style="background: #FF5582A6;">**决定观众视线在画面中的落点和路径**。</mark>
    *   **关键洞察**：材料指出，AI默认输出是“居中、平面、人物占满”，这被称为“短视频味儿”。因此，**“不用中心构图，就已经赢了50%”**。这要求创作者主动选择其他6种构图来打破AI的默认模式。
    *   **复用策略**：材料为每种构图都提供了明确的“使用条件”和“提示词模板”，使其成为可复用的原子化工具。例如，三分法被定义为“AI时代的基本盘”，是90%镜头的起手式；对角线构图则被限定在“运动/战斗/奔跑”等动态场景。

2.  **物质层：2类前景构建空间纵深**
    *   材料引入了大师的AI小灶的“2类前景”（物理遮挡型P-01、氛围粒子型P-02），并将其定义为“物质层”。这2类前景的核心功能是**为镜头提供“在那个空间里”的证据，打破AI画面的“塑料感”和“真空感”**。
    *   **关键洞察**：物理遮挡（如窗框、栏杆）让镜头有了“物理位置”，证明了摄影机是“站在某处”拍摄的。氛围粒子（如灰尘、雨丝）则让“空气有了质感”，证明了空间不是真空的。
    *   **复用策略**：材料提供了10种具体的物理遮挡物和10种氛围粒子，并给出了“只挑1种，不要堆叠”的减法原则（Subtractive Prompting），确保效果精准而不混乱。

3.  **合流点：C-07前景构图**
