### 精简版模板（可直接复制）

```markdown
# AGENTS.md — Codex / AI 编程助手的协作说明书

## 1. 语言使用规范
- 日常沟通：中文
- 代码 / 变量 / 日志 / 报错：英文

## 2. 代码与提交规范
- 单次改动尽量小，函数 < 50 行
- 单 PR < 200 行
- 提交信息使用 Conventional Commits 格式
  - feat(scope): 新功能
  - fix(scope): 修 bug
  - refactor(scope): 重构（无功能变化）

## 3. 安全红线
- 禁止在代码中硬编码 API Key / Token / 密码 / 私钥
- 禁止未经确认执行：rm -rf / force push / drop table
- 任何写操作（修改 / 删除 / 推送）前必须先报告

## 4. 执行与测试
- 先写复现测试，再修 bug
- 报错原文照贴，不吞异常
- 测试不通过 = 任务未完成

## 5. 沟通风格
- 直入主题，不寒暄
- 重视输出质量而非形式
- 一次只做一件事

## 6. Skill 调用
- 任务明显匹配 Skill 时，优先调用
- 写文档 → html-report
- 画图 → frontend-design
- 数据分析 → data-analysis
```

### 行动清单

1. **创建文件**：在项目根目录创建 `AGENTS.md`，和 `README.md` 同级
2. **填入规则**：至少填完语言、代码、提交、安全 4 个模块
3. **持续迭代**：每次发现"又重复纠正 AI 同一件事"时，立即追加一条规则

> 不要等"完美"才开始写。AGENTS.md 是"活的契约"——你写它的瞬间它就在帮你省时间。
