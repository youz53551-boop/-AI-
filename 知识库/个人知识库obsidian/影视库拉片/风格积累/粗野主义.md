# 粗野主义 × 导演思维六大维度 · 知识点映射

基于你笔记中的粗野主义内容，提取与六大维度直接相关的知识点，无关内容已剔除。

---

## 一、景别逻辑

### 1. 大远景 = 体量感的唯一载体

粗野主义场景的景别永远从**大远景**开始。第一镜必须是建筑的全身像，人物在画面中只占 **1/30**。先让观众感受体量，再让人进入。

**复用逻辑**：任何需要“渺小感”的场景（反派巢穴、异星神殿、巨型建筑），第一镜固定用大远景。

### 2. 景别递进：体量 → 人物 → 细节

粗野主义的景别递进是**反向**的：大远景（展示体量）→ 中景（人物进入）→ 特写（材质细节）。不是“从远到近”，而是“从大到小”。

**与《泰坦尼克号》的对比**：
- 《泰坦尼克号》：远→中→近（关系升温）
- 粗野主义：大远景→中景→特写（体量→人→材质）

## 二、构图设计

### 1. 中央对称 + 消失点

粗野主义建筑天然适合**中央对称构图**。把镜头放在走廊中轴线/楼梯中线/门洞中线，消失点直接打到建筑深处。极简又极有力量。

**复用模板**：
```
场景：角色行走在粗野主义走廊
构图：中央对称，消失点在画面正中
效果：观众视线被“吸”向建筑深处
```

### 2. 框中框 = 被困感

粗野主义的窄缝门窗天然形成“框中框”。人物被框在混凝土墙体之间，隐喻“被困在体量中”。

**与《白日梦想家》的对比**：
- 《白日梦想家》：框中框 = 被困在自我
- 粗野主义：框中框 = 被困在建筑/权力中

### 3. 人物占比 = 权力关系

人物在画面中的占比直接反映权力关系：
- **1/30**：人被建筑吞噬（权力在建筑）
- **1/10**：人与建筑共存（权力平衡）
- **1/3**：人开始主导空间（权力在人）

## 三、色彩情绪

### 1. 冷灰主调 + 1个暖锚

粗野主义的色彩公式：**60%冷灰 + 30%中性 + 10%暖色锚点**。

| 色调 | 占比 | 功能 |
|------|------|------|
| 冷灰（混凝土本色） | 60% | 建立“裸露即力量”的基调 |
| 中性（白/黑/灰） | 30% | 过渡与缓冲 |
| 暖色锚点（黄铜/琥珀/锈橙） | 10% | 视觉记忆点，从“压迫”走向“高级” |

**暖色不能多**：1个黄铜台灯/1件锈橙家具/1幅赭石挂画/1束琥珀顶光，就是全部。

### 2. 色彩 = 文明等级

《沙丘》的案例：同样粗野主义语言，色彩一变，气质全变。
- **卡拉丹（亚崔迪家族）**：暖色粗野主义（沙黄/灰白）
- **哈克南（反派家族）**：冷色粗野主义（灰黑/钢蓝）

**复用逻辑**：用色彩区分阵营，不需要台词。

### 3. 3种天气 = 3种类型

同样粗野主义建筑，换天气就换类型：
- **粗野主义 + 阴雨/雪/雾** = 反乌托邦（《使女的故事》《怪奇物语》）
- **粗野主义 + 沙漠/黄昏** = 史诗（《沙丘》）
- **粗野主义 + 雨夜霓虹** = 赛博朋克（《银翼杀手2049》）

## 四、光影设计

### 1. 把光切成长条

粗野主义的光是**被建筑切割过的光**。门窗是窄缝，光只能以“光柱”形态进入。这是粗野主义最标志性的光影手法。

**技术规格**：
- 光柱宽度：30cm-50cm
- 墙体高度：8-10米
- 光柱宽度 ÷ 墙体高度 ≤ 1:10

**《银翼杀手2049》的天花板案例**：镭射光穿缝，光从顶部一条30公分宽的缝打下来。

### 2. 硬光 = 注意力聚焦

粗野主义几乎只用**硬光**（硬光源，高反差）。暗部几乎黑成一团，观众的注意力被“逼”向亮部。

**与《盗梦空间》的对照**：
- 《盗梦空间》：硬光 = 静态版的特写镜头
- 粗野主义：硬光 = 让观众“被迫”注视建筑的体量与质地

### 3. 光影对比 = 情绪放大器

| 光影手法 | 效果 | 复用场景 |
|---------|------|---------|
| 顶光倾泻 | 神圣感/压迫感 | 仪式空间、反派巢穴 |
| 侧光雕刻墙体 | 凸显材质颗粒感 | 展示混凝土纹理 |
| 缝隙光 | 制造“光被建筑切割”的视觉 | 走廊、门洞 |
| 逆光剪影 | 神秘感/距离感 | 人物出场、建筑轮廓 |

## 五、运镜策略

### 1. 长镜头优先

粗野主义场景不适合快切。镜长至少 **8秒**，给观众扫视体量的时间。剪辑点是“视线”而不是“动作”——观众看哪里，就切哪里。

**与《泰坦尼克号》的对比**：
- 《泰坦尼克号》前90分钟：25-40秒/镜头（仪式化慢剪）
- 粗野主义：8秒+/镜头（让观众消化体量）

### 2. 缓慢平移 = 体量扫描

粗野主义建筑的运镜以**缓慢平移**为主。镜头沿着建筑立面水平移动，让观众“扫描”混凝土的纹理与体量。

**复用模板**：
```
场景：展示粗野主义建筑全貌
运镜：从建筑左侧缓慢平移到右侧，速度约10秒/10米
效果：观众“扫描”建筑的每一寸体量
```

### 3. 固定机位 = 让建筑“自己说话”

粗野主义场景大量使用**固定机位**。镜头不动，让建筑本身的体量和光影“自己表演”。

**与《白日梦想家》的对比**：
- 《白日梦想家》：固定机位 = 死水一样的日常
- 粗野主义：固定机位 = 让建筑“自己成为主角”

## 六、声音层次

### 1. 低频持续 + 风声

粗野主义空间的声学特征：
- **长混响**：混凝土墙面反射声音，混响时间长
- **低频共振**：建筑体量本身产生低频共鸣
- **风声穿过窄缝**：窄缝门窗让风声成为“建筑的声音”

**复用模板**：
```
场景：粗野主义建筑内部
声音设计：
  1. 底层：低频持续铺底（Hans Zimmer《沙丘》风格）
  2. 中层：风声穿过窄缝（作为cue点）
  3. 上层：偶尔的脚步声/金属回声
```

### 2. 声音先导（J-Cut）在粗野主义中的特殊用法

粗野主义建筑的声音先导不是“环境先导”，而是**“体量先导”**——先听到建筑的混响/回声，再看到建筑本身。

**复用模板**：
```
场景：角色进入粗野主义建筑
声音设计：
  1. 画面还在室外：先出现室内的混响回声（1-2秒）
  2. 画面切到室内：声音与画面同步
  3. 效果：观众“提前进入”建筑的声学空间
```

### 3. 沉默 = 体量的“重量”

粗野主义场景的沉默不是“没声音”，而是**“用没声音做强调”**。当所有声音消失，建筑的体量感反而被放大。

**与《泰坦尼克号》的对比**：
- 《泰坦尼克号》：沉默 = 死亡/窒息（杰克沉入水中）
- 粗野主义：沉默 = 体量的“重量”（让建筑本身“发声”）
