# AIGC 打戏拆解知识库 — 整体框架

## 一、视觉风格基座
- **核心调性**：暗黑深空 + 金色能量光效 + 赛博仙侠融合
- **色彩倾向**：低饱和度背景（深蓝/黑/紫），高饱和金色/橙色作为能量与攻击高光
- **材质参考**：金属质感（冷硬）、能量流体（半透明发光）、粒子雾效

## 二、镜头设计
- **景别策略**：全景（交代空间与走位）→ 中景（动作交互）→ 特写（武器碰撞/表情/能量爆发）
- **运镜轨迹**：跟随（角色冲刺）、环绕（对峙/蓄力）、推拉（冲击波/爆发瞬间）
- **构图法则**：三分法（角色偏一侧留出能量轨迹空间）、对角线（增强动势）、中心对称（大招/对峙）
- **视角切换节奏**：主观视角（第一人称格挡/闪避）→ 客观视角（全景连招）→ 慢动作特写（关键帧）

## 三、动作编排
- **攻击/防御模式**：
  - 攻击：突刺、横斩、上挑、连击、蓄力重击
  - 防御：格挡（武器碰撞火花）、闪避（侧翻/后跳/瞬移）、弹反（金色冲击波）
- **连招组合设计**：轻击×2 → 重击（击飞）→ 追击（空中连斩）→ 终结技（能量爆发）
- **节奏与呼吸**：快（连击/闪避）→ 慢（蓄力/对峙/特写）→ 极快（爆发/终结）
- **角色空间走位**：直线冲刺（突进）、弧线走位（绕后）、垂直位移（腾空/下落）

## 四、特效与能量
- **能量光效类型**：
  - 武器附魔（持续发光拖尾）
  - 蓄力光球（聚集在掌心/剑尖）
  - 爆发光环（圆形扩散）
  - 轨迹光线（斩击路径）
- **粒子与碎片**：
  - 碰撞火花（金属×金属）
  - 能量碎片（光效碎裂消散）
  - 环境破坏（地面裂痕/碎石飞溅）
- **碰撞冲击波**：瞬间白色/金色环形扩散，伴随屏幕震动
- **武器拖尾/光影**：慢动作下清晰可见的弧形光轨

### 1.2 节奏匹配规则

| 动作阶段 | 音效处理 | 示例 |
|----------|----------|------|
| **慢动作** | 音效拉长（时间拉伸）+ 加重混响 + 降低高频 | 刀剑碰撞瞬间，金属声拉长至1.5秒，带空间回响 |
| **快节奏连招** | 音效密集叠加，每0.2-0.3秒一个命中音，不重叠 | 轻击×3：铛铛铛，每个音效0.1秒，间隔0.1秒 |
| **蓄力阶段** | 低频嗡鸣渐强，音量从20%升至80%，持续1-2秒 | 剑尖聚集金色能量，嗡鸣声随光球变大而增强 |
| **爆发瞬间** | 前0.1秒静音 → 瞬间巨响（冲击波+金属碰撞+玻璃碎裂混合） | 大招释放，全频段爆裂，持续0.5秒后快速衰减 |
| **终结定格** | 所有音效骤停 → 0.5秒静默 → 一声沉重金属回响（带尾音） | 最后一刀命中，画面定格，音效回响2秒后淡出 |

## 视觉风格基座（重构）

### 核心感受一句话
> **“在宇宙深渊里，两位仙人用光在战斗。”**

### 分维度感官描述

#### 1. 空间感：不是“暗黑深空”，而是“有重量的虚空”
- 背景不是纯黑，而是**深到发蓝的宇宙底色**，像深夜仰望没有星星的天空
- 远处有**微弱的星点或尘埃漂浮**，让人感觉空间是无限的、有深度的
- 角色站在**虚无之上**，脚下没有地面，但有**能量涟漪**随着脚步扩散，暗示“这里是有实体的虚空”
- **感受**：压抑、孤独、宏大，像在太空站窗外看无尽黑暗

#### 2. 光效：不是“金色能量”，而是“有温度的光”
- 金色不是亮黄色，而是**熔岩般的橙金**，像铁水在流动
- 光效**不是均匀发光**，而是**从内部燃烧出来**的——中心炽白，边缘橙红，最外层是暗金色余晖
- 光在空气中**留下残影**，像用燃烧的树枝在空中写字，轨迹会停留0.3秒才消散
- 光打在角色脸上时，**半边脸被照亮，半边脸沉入黑暗**，形成强烈的明暗对比
- **感受**：炽热、危险、神圣，像触碰就会被灼伤

#### 3. 材质：不是“赛博仙侠”，而是“古老与未来的碰撞”
- 武器：剑身是**古代青铜器的质感**，但表面有**流动的霓虹纹路**，像电路板嵌入青铜
- 铠甲：**硬表面+布料**——肩甲是金属（有磨损划痕），衣摆是丝绸（在真空中缓慢飘动）

## 碰撞反应系统（重构版）

### 一、按命中部位分类

| 命中部位 | 反应 | 后续效果 | 视觉表现 |
|----------|------|----------|----------|
| **头部** | 头部后仰 + 身体跟随后退 | 短暂眩晕（0.5秒内动作迟缓） | 头发/头盔碎片飞溅，金色火星 |

| **武器** | 武器脱手 + 旋转飞出 | 角色空手，需要重新召武器或捡起 | 武器在空中旋转，拖出金色光轨 |

### 二、按攻击方向分类

| 攻击方向 | 反应 | 视觉表现 |
|----------|------|----------|
| **正面直刺** | 身体向后弓起 + 双脚擦地后退 | 胸口能量爆裂，冲击波从背后扩散 |
| **侧面横斩** | 身体向反侧倾斜 + 旋转半圈 | 腰部/肋部光效迸发，身体旋转时带出金色弧线 |
| **上挑** | 身体浮空 + 四肢张开 | 脚下冲击波，身体腾空0.5-1秒后重重落地 |
| **下劈** | 身体下蹲 + 单膝跪地 + 地面裂开 | 肩膀/头部承受冲击，地面以落脚点为中心龟裂 |
| **背后攻击** | 身体前扑 + 翻滚落地 | 背部光效爆裂，前扑时武器脱手 |
| **从上方攻击** | 身体被压向地面 + 四肢贴地 | 地面凹陷，周围碎石飞起 |

### 三、按武器类型分类

| 武器类型 | 命中反应特征 | 特殊效果 |
|----------|-------------|----------|
| **剑/刀（切割）** | 伤口处先出现一条细线，0.1秒后鲜血/能量喷涌 | 衣物/皮肤上有整齐切口，边缘发光 |
| **锤/棍（钝击）** | 命中处凹陷 + 身体整体位移 | 不流血，但骨骼变形（铠甲凹陷），内伤表现为嘴角溢血 |

| **能量波（冲击）** | 身体被推飞 + 空中旋转多圈 | 全身被能量包裹，落地后滑行一段距离 |
| **暗器/飞镖** | 身体局部抽搐 + 伸手去拔 | 命中处有细小光点，拔除时带出血丝 |

### 四、按双方状态分类

| 攻击者状态 | 被攻击者状态 | 反应变化 |
|------------|-------------|----------|
| **满血/全力** | 满血/满防 | 标准反应（如上表） |
| **满血/全力** | 残血/残防 | 反应放大：击飞距离翻倍，倒地后无法立即起身 |
| **残血/虚弱** | 满血/满防 | 反应缩小：仅轻微后仰，被攻击者几乎不受影响 |
| **蓄力攻击** | 任何状态 | 反应增强：命中时画面定格1-2帧，冲击波范围扩大 |
| **仓促攻击** | 任何状态 | 反应减弱：被攻击者仅后退半步，立刻反击 |

|----------|------|----------|
| 第1击 | 后仰 + 后退1步 | 轻微火花 |
| 第2击 | 身体倾斜 + 后退2步 | 火花变大，衣物破损 |
| 第3击 | 单膝跪地 + 武器撑地 | 能量从伤口泄漏 |
| 第4击 | 击飞 + 空中旋转 | 全身光效爆裂，空中拖出光轨 |
| 第5击（终结） | 撞墙/倒地 + 武器脱手 | 全屏冲击波，地面龟裂，角色陷入地面 |

### 六、环境交互反应

被击中的角色不应该只停留在原地，应该与**环境产生互动**：

| 环境类型 | 碰撞反应 |
|----------|----------|
| **地面** | 滑行一段距离（留下两道划痕），或砸出一个人形坑 |
| **墙壁** | 撞墙后墙面龟裂，身体贴墙滑落，墙上留下能量残留 |
| **柱子/岩石** | 撞断柱子/撞碎岩石，碎石飞溅，角色被埋在碎石下 |
| **水面** | 在水面滑行（激起水花），或沉入水中（气泡上涌） |
| **虚空/空中** | 空中翻滚多圈后稳住身形，或坠落一段距离后重新悬浮 |

### 七、反应时间线（以一次重击为例）

```
T+0.00s：武器接触身体（接触帧停顿1-2帧）
T+0.02s：冲击波从接触点扩散（环形金色光效）
T+0.05s：身体开始变形（凹陷/弯曲/撕裂）
T+0.10s：身体被击飞（双脚离地）
T+0.15s：空中旋转（衣物/头发飘动，光效拖尾）
T+0.30s：撞墙/落地（第二次冲击波，地面龟裂）
T+0.50s：滑落/静止（身体抽搐一下，然后不动）
T+1.00s：能量残留消散（伤口处光点慢慢熄灭）
```

## 镜头设计（重构）

### 核心原则
> **镜头不是记录打戏，而是放大情绪。**

每一次景别切换、运镜变化、构图选择，都应该让观众**感受到**这一瞬间的情绪——是紧张、是震撼、是窒息、还是释放。

---

### 一、景别策略：不是线性推进，而是情绪切换

| 景别 | 什么时候用 | 为什么用 | 情绪效果 |
|------|-----------|----------|----------|
| **远景** | 打戏开始前/结束后，或双方拉开距离对峙时 | 交代空间关系，让观众看清两人之间的距离和位置 | 冷静、客观、像旁观者 |
| **全景** | 连招进行中、双方快速移动时 | 让观众看清完整的动作轨迹和走位 | 流畅、舒展、有舞蹈感 |
| **中景** | 单次攻击/格挡、技能释放时 | 聚焦在武器碰撞或能量爆发的瞬间，去掉多余环境干扰 | 集中、有力、打击感最强 |
| **近景** | 角色表情变化、受伤反应、蓄力时 | 让观众看到角色的情绪——愤怒、痛苦、专注 | 代入、共情、紧张 |
| **特写** | 武器碰撞瞬间、能量爆发前一刻、致命一击命中时 | 放大细节，让观众看清平时看不清的瞬间 | 震撼、窒息、时间仿佛停止 |

**切换逻辑**：不是按顺序走一遍，而是**根据情绪曲线来回跳**。

```
对峙（远景/全景）
  ↓
试探攻击（中景）
  ↓
一方被击中（近景/特写）
  ↓
反击连招（全景）
  ↓
大招蓄力（近景→特写）
  ↓
爆发（全景/特写快速切换）
```

---

### 二、运镜轨迹：每种运镜对应一种情绪

| 运镜方式 | 什么时候用 | 情绪效果 | 操作要点 |
|----------|-----------|----------|----------|
| **跟随** | 角色冲刺、追击、逃跑时 | 让观众感觉自己跟在角色身后，有代入感 | 镜头与角色保持固定距离，速度一致 |
| **环绕** | 对峙、蓄力、大招前摇时 | 让观众从各个角度观察角色，营造“审视”感 | 以角色为中心，缓慢匀速旋转（180°-360°） |
| **推近** | 蓄力即将完成、攻击即将命中时 | 逐渐逼近，制造紧张感，像危险在靠近 | 从全景匀速推到特写，速度由慢变快 |
| **拉远** | 大招爆发、冲击波扩散时 | 突然拉开距离，让观众看到全貌，感受“宏大” | 从特写快速拉到全景，速度由快变慢 |
| **上仰** | 角色腾空、从下往上攻击时 | 让角色显得高大、有压迫感 | 镜头从低处向上拍，角色占据画面上半部分 |
| **俯拍** | 角色倒地、从上往下攻击时 | 让角色显得渺小、脆弱 | 镜头从高处向下拍，角色被压向画面底部 |
| **晃动** | 被击中、爆炸冲击时 | 模拟受冲击的视觉感受，让观众“感觉到”撞击 | 短促、不规则抖动，持续0.3-0.5秒 |
| **静止** | 致命一击命中、终结定格时 | 突然静止，与之前的运动形成反差，放大冲击力 | 画面完全静止1-2秒，然后缓慢恢复运动 |

**运镜组合示例**（一次大招释放）：

```
蓄力阶段：环绕（缓慢，让观众看清能量聚集）
  ↓
释放前一刻：推近（快速，从全景推到特写）
  ↓
爆发瞬间：拉远（极快，从特写拉到远景）+ 晃动（0.3秒）
  ↓
命中后：静止（1秒，定格在角色被击中的瞬间）
```

---

### 三、构图法则：每种构图对应一种力量关系

| 构图方式 | 什么时候用 | 力量关系 | 视觉表现 |
|----------|-----------|----------|----------|
| **三分法** | 单角色行动（冲刺/蓄力/攻击） | 角色是主体，环境是陪衬 | 角色放在左侧或右侧1/3处，面向方向留出2/3空间 |
| **中心对称** | 双方对峙、对波、大招碰撞 | 双方力量均等，势均力敌 | 两人分居画面左右，中间留出能量碰撞点 |
| **对角线** | 一方攻击、一方防御/闪避 | 力量有方向性，一方主动一方被动 | 攻击者在上方对角线，防御者在下方对角线 |
| **极低角度仰拍** | 胜利者、大招释放者 | 被拍者占据绝对优势，有压迫感 | 镜头贴近地面，角色占据画面大部分 |
| **极高角度俯拍** | 失败者、倒地者 | 被拍者处于劣势，显得渺小 | 镜头从正上方俯拍，角色缩在画面中央 |
| **框架构图** | 角色穿过门/窗/裂缝时 | 增加空间层次感，暗示“穿越”或“进入新阶段” | 利用环境元素（石柱/树枝/建筑）作为前景框架 |
| **留白构图** | 大招前摇、终结一击前 | 制造悬念，让观众期待接下来会发生什么 | 角色放在画面边缘，大部分区域是空的（虚空/天空） |

**构图切换逻辑**：随着力量关系的变化而变化。

```
双方势均力敌 → 中心对称
  ↓
一方开始蓄力 → 留白构图（蓄力者占小部分，空出能量方向）
  ↓
蓄力完成 → 极低角度仰拍（蓄力者显得高大）
  ↓
攻击命中 → 对角线（攻击者在上，被击者在下）
  ↓
被击者倒地 → 极高角度俯拍（被击者渺小）
```

---

### 四、视角切换节奏：不是固定顺序，而是情绪呼吸

| 视角类型 | 什么时候用 | 情绪效果 | 持续时间 |
|----------|-----------|----------|----------|
| **客观视角** | 大部分时间 | 让观众以旁观者身份看清全局 | 3-5秒 |
| **主观视角** | 格挡/闪避/被击中瞬间 | 让观众“成为”角色，感受冲击 | 0.5-1秒 |
| **慢动作** | 关键帧（碰撞/爆发/终结） | 放大瞬间，让观众看清细节 | 1-2秒（实际时间0.3秒） |
| **升格（快放）** | 连招/追击/翻滚 | 加快节奏，制造紧迫感 | 0.5-1秒 |

**视角切换节奏模板**（以一次完整交锋为例）：

```
客观视角（全景，双方对峙，3秒）
  ↓
主观视角（第一人称，对方冲刺过来，0.5秒）
  ↓
客观视角（中景，格挡成功，火花四溅，1秒）
  ↓
慢动作（特写，武器碰撞瞬间，1秒）
  ↓
客观视角（全景，双方弹开，2秒）
  ↓
升格（快放，一方追击，0.5秒）
  ↓
客观视角（中景，连招开始，2秒）
  ↓
慢动作（特写，最后一击命中，1.5秒）
  ↓
客观视角（远景，一方倒地，3秒）
```

---

### 总结：镜头设计一句话

> **景别控制观众看到什么，运镜控制观众感受到什么，构图暗示力量关系，视角切换控制呼吸节奏。**

四个要素不是独立工作的，而是**同时配合**。例如：

- **大招爆发瞬间**：特写（景别）+ 拉远（运镜）+ 中心对称（构图）+ 慢动作（视角）
- **被击中瞬间**：近景（景别）+ 晃动（运镜）+ 对角线（构图）+ 主观视角（视角）

## 新增：场景情绪分类（镜头设计的上层指导）

### 核心原则
> **先定情绪，再定镜头。同一套镜头技法，换一种情绪组合，就是完全不同的打戏。**

---

### 一、六大打戏情绪基调

| 情绪基调 | 一句话感受 | 适用场景举例 | 核心情绪关键词 |
|----------|-----------|-------------|---------------|
| **悲壮** | 明知会输，还是要打 | 主角为保护某人断后、牺牲前的最后一战 | 沉重、缓慢、不舍、决绝 |
| **愤怒** | 失去理智，只想撕碎对方 | 亲友被杀后的复仇战、被背叛后的爆发 | 狂暴、混乱、不计代价 |
| **优雅** | 不是打架，是表演 | 高手对决、宗师切磋、刺客的暗杀 | 从容、精准、行云流水 |
| **绝望** | 无论如何都赢不了 | 面对远超自己的敌人、被碾压的战斗 | 无力、挣扎、窒息感 |
| **碾压** | 单方面屠杀 | 满级大佬回新手村、BOSS虐菜 | 轻松、随意、不对称 |
| **焦灼** | 五五开，谁先失误谁死 | 宿命对决、决赛圈、生死局 | 紧张、谨慎、每一帧都致命 |

---

### 二、每种情绪对应的镜头策略

#### 1. 悲壮

| 镜头要素 | 策略 |
|----------|------|
| **景别偏好** | 远景（强调孤独感）+ 近景/特写（强调表情：疲惫、不舍、微笑） |
| **运镜偏好** | 缓慢环绕（像在告别）+ 静止（定格在角色脸上）+ 极慢的推近 |
| **构图偏好** | 留白构图（角色占小部分，大部分是虚空/天空）+ 极低角度仰拍（让牺牲显得崇高） |
| **视角节奏** | 慢动作占比高（30%以上），主观视角少（不需要代入，而是旁观这场牺牲） |
| **色彩倾向** | 暗部偏蓝紫，金色光效偏暗、偏暖橙（像余晖） |
| **节奏特征** | 整体偏慢，动作之间有明显的停顿（呼吸、对视、微笑） |

**示例场景**：主角被贯穿后，缓缓转身，对身后的人笑了一下，然后举起剑冲向敌人。镜头从特写（笑容）缓慢拉远到远景（冲向敌人的背影），慢动作。

---

#### 2. 愤怒

| 镜头要素 | 策略 |
|----------|------|
| **景别偏好** | 近景/特写（强调表情：咬牙切齿、青筋暴起）+ 中景（动作） |
| **运镜偏好** | 晃动（被击中/主动撞击）+ 快速推近（冲向敌人）+ 跟随（追击） |
| **构图偏好** | 对角线（攻击方在上，压迫感）+ 极低角度仰拍（让愤怒者显得巨大） |
| **视角节奏** | 主观视角占比高（让观众感受愤怒者的视角），慢动作少（愤怒不需要慢，需要快） |
| **色彩倾向** | 金色光效偏红、偏亮，背景暗部更黑（对比更强烈） |
| **节奏特征** | 整体偏快，连招之间几乎没有停顿，攻击频率越来越高 |

**示例场景**：主角看到亲友被杀，怒吼着冲向敌人。镜头从特写（瞪大的眼睛）快速切换到主观视角（冲向敌人），然后是一连串快速的中景连招，每次命中都伴随屏幕晃动。

---

#### 3. 优雅

| 镜头要素 | 策略 |
|----------|------|
| **景别偏好** | 全景（展示完整动作轨迹）+ 特写（武器尖端/脚尖/指尖） |
| **运镜偏好** | 环绕（缓慢、匀速，像在欣赏舞蹈）+ 跟随（保持固定距离，不晃） |
| **构图偏好** | 三分法（角色在1/3处，面向方向留出2/3）+ 对称（动作起始和结束位置对称） |
| **视角节奏** | 慢动作占比高（展示每一个动作的细节和美感），主观视角少（不需要代入，而是欣赏） |
| **色彩倾向** | 金色光效偏亮、偏淡，有柔光效果，背景偏灰蓝（像水墨画） |
| **节奏特征** | 动作之间有明显的“起势”和“收势”，像太极或舞蹈 |

**示例场景**：刺客在月光下与多名敌人交手。镜头以环绕为主，每次攻击都伴随慢动作，展示剑刃划过空气时留下的金色光轨。角色落地时，衣摆缓缓落下，然后才进入下一个动作。

---

#### 4. 绝望

| 镜头要素 | 策略 |
|----------|------|
| **景别偏好** | 远景（强调敌人的巨大/环境的压迫）+ 极低角度仰拍（看敌人）+ 极高角度俯拍（看自己） |
| **运镜偏好** | 缓慢拉远（强调无力感）+ 晃动（被击中）+ 静止（定格在绝望的表情上） |
| **构图偏好** | 框架构图（透过裂缝/废墟看敌人，暗示被困住）+ 留白构图（角色缩在角落） |
| **视角节奏** | 主观视角占比高（让观众感受绝望者的视角——看到敌人逼近却无力反抗），慢动作集中在被击中的瞬间 |
| **色彩倾向** | 金色光效偏暗、偏冷，几乎被黑暗吞噬，背景几乎全黑 |
| **节奏特征** | 整体偏慢，动作之间有长时间的停顿（喘息、颤抖、爬不起来） |

**示例场景**：主角被敌人踩在脚下。镜头从极低角度仰拍（看到敌人巨大的身影），切换到主观视角（看到敌人举起武器），然后缓慢拉远（看到主角蜷缩在地上）。慢动作集中在主角试图爬起来又被踩下去的瞬间。

---

#### 5. 碾压

| 镜头要素 | 策略 |
|----------|------|
| **景别偏好** | 中景（展示单次攻击）+ 特写（碾压者的表情：无聊/轻蔑） |
| **运镜偏好** | 静止（碾压者几乎不需要移动）+ 快速推近（碾压者出手的瞬间） |
| **构图偏好** | 极低角度仰拍（碾压者占据大部分画面）+ 对角线（碾压者在上，被碾压者在下） |
| **视角节奏** | 慢动作集中在被碾压者飞出去的瞬间（强调“惨”），碾压者的动作用正常速度甚至快放（强调“轻松”） |
| **色彩倾向** | 碾压者的光效极亮、极金，被碾压者的光效暗淡、破碎 |
| **节奏特征** | 碾压者动作极简（一招就够了），被碾压者动作极多（翻滚/飞出去/撞墙/再飞出去） |

**示例场景**：满级大佬随手一挥，对手飞出去撞断三根柱子。镜头用静止拍摄大佬，用跟随拍摄飞出去的对手。慢动作集中在对手撞断柱子的瞬间，碎石飞溅。

---

#### 6. 焦灼

| 镜头要素 | 策略 |
|----------|------|
| **景别偏好** | 中景（展示攻防转换）+ 近景（表情：紧张、专注、流汗） |
| **运镜偏好** | 环绕（双方互相环绕，寻找破绽）+ 快速切换（攻击方→防御方→攻击方） |
| **构图偏好** | 中心对称（双方势均力敌）+ 三分法（一方攻击时，另一方在画面另一侧准备反击） |
| **视角节奏** | 客观视角和主观视角快速切换（让观众感受双方的紧张），慢动作集中在“差一点就命中”的瞬间 |
| **色彩倾向** | 金色光效双方均等，没有明显偏向，背景中性 |
| **节奏特征** | 攻防转换极快，没有明显的“蓄力→爆发”阶段，每一秒都在博弈 |

**示例场景**：两人在悬崖边对决。镜头在两人之间快速切换，每次攻击都差一点命中。慢动作集中在剑刃擦过脸颊、刺穿衣角的瞬间。双方都在喘气，都在找对方的破绽。

## 动作编排（重构）

### 核心原则
> **动作不是招式堆砌，而是角色情绪和战斗意图的外化。**

每一次攻击、每一次防御、每一次走位，都应该让观众看懂角色**想干什么**——是想杀死对方、逼退对方、还是拖延时间。

---

### 一、攻击/防御模式：按战斗意图分类

#### 1. 攻击意图

| 攻击类型 | 动作特征 | 什么时候用 | 情绪效果 |
|----------|----------|-----------|----------|
| **试探** | 快速、幅度小、收招快（刺一下立刻收回） | 开局、面对未知对手、寻找破绽 | 谨慎、冷静 |
| **压制** | 连续、密集、不追求命中率（逼对方走位） | 占据优势时、想把对方逼到角落 | 强势、侵略 |
| **致命** | 蓄力、大幅度的终结一击（赌上一切） | 确定破绽时、最后一击、同归于尽 | 决绝、危险 |
| **牵制** | 攻击不指向身体，指向对方下一步位置 | 阻止对方靠近/逃跑/施法 | 控制、算计 |
| **泄愤** | 无章法、大开大合、不计体力 | 愤怒、失去理智、被激怒 | 狂暴、混乱 |

#### 2. 防御意图

| 防御类型 | 动作特征 | 什么时候用 | 情绪效果 |
|----------|----------|-----------|----------|
| **硬抗** | 武器/手臂正面格挡，不退 | 不能退的时候（身后有人/悬崖） | 坚决、悲壮 |
| **卸力** | 格挡同时后退/侧身，让攻击滑开 | 面对重击、想保存体力 | 技巧、从容 |
| **闪避** | 完全躲开攻击（侧翻/后跳/瞬移） | 面对无法格挡的攻击、寻找反击机会 | 灵活、冷静 |
| **弹反** | 在攻击命中的瞬间格挡，触发反击 | 高手对决、想快速结束战斗 | 精准、自信 |
| **逃跑** | 转身就跑/飞走 | 打不过、战略性撤退 | 狼狈、务实 |

#### 3. 攻防转换逻辑

```
攻击命中 → 继续压制（连招）
攻击被格挡 → 收招防守（防止反击）
攻击落空 → 立刻闪避（防止被抓住硬直）
防御成功 → 立刻反击（弹反/格挡后反击）
防御被破 → 紧急闪避/硬吃下一击
```

---

### 二、连招组合设计：按情绪基调定制

#### 1. 悲壮连招

```
动作特征：慢、重、每一击都像最后一击
节奏：蓄力（1秒）→ 重击 → 停顿（喘息）→ 蓄力 → 重击
走位：直线推进（不退，每一步都向前）
连招模板：
  蓄力横斩（逼退敌人）→ 停顿（胸口起伏）→ 蓄力上挑（击飞）→ 追击（空中抱住敌人一起坠落）
情绪目的：让观众感受到“他在燃烧自己”
```

#### 2. 愤怒连招

```
动作特征：快、乱、不计后果
节奏：连续攻击（无停顿）→ 被格挡 → 更疯狂地攻击
走位：直线冲刺（不绕后，正面硬刚）
连招模板：
  突刺×3（压制）→ 横斩（被格挡）→ 怒吼 → 乱舞（无章法连续挥砍）→ 蓄力重击（终结）
情绪目的：让观众感受到“他失控了”
```

#### 3. 优雅连招

```
动作特征：流畅、精准、每一击都有预留后手
节奏：攻击（0.3秒）→ 收招（0.2秒）→ 观察 → 攻击
走位：弧线走位（绕后/侧击，不与对方正面硬拼）
连招模板：
  侧步 → 刺手腕（缴械）→ 转身 → 横斩腰部 → 收招（剑尖下垂）→ 等待对方反应
情绪目的：让观众感受到“他在戏弄对手”
```

#### 4. 绝望连招

```
动作特征：无力、挣扎、被中断
节奏：攻击 → 被格挡/闪避 → 被反击 → 倒地 → 爬起来 → 再攻击
走位：后退为主（被逼退），偶尔前冲（被击退）
连招模板：
  突刺（被闪避）→ 被击中 → 后退 → 蓄力（被中断）→ 被击飞 → 爬行（试图够武器）
情绪目的：让观众感受到“他赢不了”
```

#### 5. 碾压连招

```
动作特征：极简、随意、一招就够了
节奏：静止（等待对方攻击）→ 随手一击 → 看对方飞出去
走位：几乎不走位（站在原地）
连招模板：
  不动（等对方冲过来）→ 侧身（闪避）→ 随手一挥（击中）→ 转身（不看结果）
情绪目的：让观众感受到“他根本没认真”
```

#### 6. 焦灼连招

```
动作特征：攻防转换极快、每一招都被化解
节奏：攻击 → 被格挡 → 立刻防守 → 对方攻击 → 格挡 → 立刻反击
走位：互相环绕（都在找破绽，都不轻易出手）
连招模板：
  刺（被格挡）→ 收招格挡（对方反击）→ 弹反 → 对方闪避 → 双方拉开 → 重新对峙
情绪目的：让观众感受到“谁先失误谁死”
```

### 三、节奏与呼吸：不是线性，是波浪形

#### 1. 节奏波浪模型

```
情绪强度
  ^
  |     /\        /\        /\
  |    /  \      /  \      /  \
  |   /    \    /    \    /    \
  |  /      \  /      \  /      \
  | /        \/        \/        \
  +----------------------------------> 时间
    波峰      波谷      波峰      波谷
```

- **波峰**：攻击密集、速度快、情绪高
- **波谷**：对峙、喘息、蓄力、情绪回落

#### 2. 不同情绪的波浪特征

| 情绪 | 波浪特征 | 波峰持续时间 | 波谷持续时间 |
|------|----------|-------------|-------------|
| **悲壮** | 波峰短而高，波谷长而沉 | 1-2秒 | 3-5秒（喘息/对视） |
| **愤怒** | 波峰长而密，几乎没有波谷 | 5-10秒连续攻击 | 0.5-1秒（怒吼后继续） |
| **优雅** | 波峰低而平，波谷从容 | 0.5-1秒（一次攻击） | 1-2秒（收招/观察） |
| **绝望** | 波峰被强行打断，波谷是被击倒 | 0.3-0.5秒（攻击被中断） | 2-4秒（倒地/爬起） |
| **碾压** | 只有一个波峰，然后结束 | 0.5秒（一招） | 无波谷（直接结束） |
| **焦灼** | 波峰波谷交替极快，幅度小 | 0.3-0.5秒（一次攻防） | 0.3-0.5秒（立刻反击） |

#### 3. 呼吸点设计

在波谷位置插入“呼吸点”，让观众和角色一起喘息：

| 呼吸点类型 | 表现 | 适用情绪 |
|-----------|------|----------|
| **对视** | 双方停下，互相盯着对方，镜头给到眼神 | 焦灼、悲壮 |
| **喘息** | 角色弯腰/扶膝，大口喘气，胸口起伏 | 愤怒（发泄后）、绝望 |
| **蓄力** | 能量聚集，光效变亮，镜头推近 | 悲壮、优雅 |
| **环境** | 镜头切到周围环境（破碎的建筑/飘落的尘埃） | 悲壮、绝望 |
| **对话** | 角色说一句话（“你变弱了”/“到此为止了”） | 碾压、优雅 |

### 四、角色空间走位：走位即意图

#### 1. 走位类型与意图

| 走位类型 | 动作特征 | 意图 | 适用情绪 |
|----------|----------|------|----------|
| **直线推进** | 正面冲向对方，不躲不闪 | 压制、拼命、同归于尽 | 愤怒、悲壮 |
| **直线后退** | 正面面对对方，向后移动 | 防守、引诱（让对方追） | 焦灼、优雅 |
| **弧线绕后** | 侧向移动，绕到对方侧面/背后 | 寻找破绽、避开正面 | 优雅、焦灼 |
| **横向闪避** | 向左右快速侧移 | 躲避攻击、重新调整位置 | 焦灼、绝望 |
| **垂直腾空** | 跳起/飞起 | 躲避地面攻击、从上往下攻击 | 优雅、愤怒 |
| **垂直下落** | 快速落地/下坠 | 躲避空中攻击、砸地攻击 | 愤怒、碾压 |
| **瞬移/闪现** | 瞬间出现在另一个位置 | 突袭、逃跑、戏弄对手 | 优雅、碾压 |
| **环绕** | 以对方为中心做圆周运动 | 观察、施压、不让对方休息 | 焦灼、优雅 |

#### 2. 走位组合示例

```
愤怒：直线推进 → 被格挡 → 直线推进（不换方向，硬破防）
优雅：弧线绕后 → 攻击 → 后退（拉开距离）→ 弧线绕另一侧
焦灼：横向闪避 → 直线推进（反击）→ 被格挡 → 横向闪避（退回安全距离）
绝望：直线后退 → 被追上 → 横向翻滚 → 爬起来 → 直线后退
```

#### 3. 走位与镜头配合

| 走位 | 推荐运镜 | 效果 |
|------|----------|------|
| 直线推进 | 跟随（从背后/侧面跟拍） | 让观众感受冲刺的速度感 |
| 弧线绕后 | 环绕（以被绕者为中心） | 让观众看清绕后的轨迹 |
| 瞬移 | 快速切换（原地→出现位置） | 强调“瞬间消失又出现”的突兀感 |
| 垂直腾空 | 上仰（从下往上拍） | 让角色显得高大、有压迫感 |

---

### 总结：动作编排一句话

> **攻击是意图，防御是态度，连招是性格，节奏是情绪，走位是策略。**

五个要素不是独立工作的，而是**同时配合**。例如：

- **悲壮打戏**：蓄力重击（攻击）+ 硬抗（防御）+ 直线推进（走位）+ 慢节奏（呼吸）+ 每一击都像最后一击（连招）
- **优雅打戏**：刺手腕（攻击）+ 卸力（防御）+ 弧线绕后（走位）+ 快慢交替（节奏）+ 行云流水（连招）

## 特效与能量（重构）

### 核心原则
> **特效不是装饰，是能量的可视化。观众通过特效读懂这一击的力度、情绪和后果。**

每一次光效、每一粒碎片、每一道冲击波，都应该让观众**感受到**这一瞬间的力量——是轻是重、是快是慢、是愤怒还是优雅。

### 一、能量光效类型：按情绪和阶段分类

#### 1. 光效的三大属性

| 属性 | 变化维度 | 情绪对应 |
|------|----------|----------|
| **颜色** | 金（中性）→ 橙红（愤怒）→ 暗橙（悲壮）→ 淡金（优雅）→ 暗金（绝望） | 颜色越暖越激烈，越暗越沉重 |
| **形态** | 聚集（蓄力）→ 爆发（释放）→ 残留（余韵） | 聚集=即将发生，爆发=正在发生，残留=已经发生 |
| **运动** | 流动（持续）→ 扩散（爆发）→ 消散（结束） | 流动=有生命，扩散=有力量，消散=有代价 |

#### 2. 六种核心光效

| 光效类型 | 形态描述 | 什么时候出现 | 情绪效果 | 视觉要点 |
|----------|----------|-------------|----------|----------|
| **武器附魔** | 武器表面覆盖一层流动的光，像液体在金属上滑动 | 角色激活能量、战斗全程（持续） | 让观众知道“这把武器是活的” | 光从剑柄流向剑尖，循环流动 |
| **蓄力光球** | 能量在掌心/剑尖聚集，从一个小点逐渐变大，内部有流动纹路 | 大招前摇、重击蓄力 | 制造紧张感，让观众知道“要来了” | 光球从乒乓球大小变成篮球大小，内部纹路越来越亮 |
| **爆发光环** | 从身体/武器中心向外扩散的环形光波，边缘清晰或模糊 | 大招释放、能量爆发、冲击波 | 让观众感受到“力量释放”的瞬间 | 光环扩散速度由快到慢，边缘颜色由亮变暗 |
| **轨迹光线** | 武器/能量经过路径上留下的光轨，持续0.3-1秒后消散 | 挥砍、突刺、能量波飞行 | 让观众看清攻击路径，感受速度 | 光轨从粗变细，从亮变暗，从实变虚 |
| **能量残留** | 命中后留在伤口/地面的光点或光斑，缓慢闪烁后熄灭 | 命中后、战斗结束后 | 让观众感受到“这一击留下了痕迹” | 光点从亮到暗，闪烁频率由快到慢 |
| **全身爆发** | 角色全身被光包裹，光从体内向外透出，像要裂开 | 极限状态、觉醒、燃烧生命 | 让观众感受到“他在燃烧自己” | 光从皮肤裂缝/经脉纹路中透出，全身发光 |

#### 3. 不同情绪的光效特征

| 情绪 | 主色 | 光效形态偏好 | 运动特征 | 亮度 |
|------|------|-------------|----------|------|
| **悲壮** | 暗橙、暖金（像余晖） | 能量残留（强调“留下痕迹”）+ 全身爆发（燃烧生命） | 缓慢流动、缓慢消散 | 中等，偏暗 |
| **愤怒** | 橙红、炽白（像火焰） | 爆发光环（强调“释放”）+ 轨迹光线（强调“速度”） | 快速扩散、剧烈闪烁 | 极亮 |
| **优雅** | 淡金、银白（像月光） | 武器附魔（强调“持续”）+ 轨迹光线（强调“轨迹”） | 平滑流动、均匀消散 | 柔和，不刺眼 |
| **绝望** | 暗金、灰金（像熄灭的灰烬） | 能量残留（强调“无力”）+ 蓄力光球（但无法完成蓄力） | 断续、不稳定、提前消散 | 暗淡 |
| **碾压** | 亮金（像正午阳光） | 爆发光环（一次就够了）+ 武器附魔（几乎不发光，因为不需要） | 极快爆发、无残留 | 极亮但短暂 |
| **焦灼** | 中性金（不偏不倚） | 轨迹光线（强调“攻防转换”）+ 蓄力光球（双方都在蓄力） | 快速出现、快速消失 | 中等 |

### 二、粒子与碎片：按材质和情绪分类

#### 1. 粒子三大属性

| 属性 | 变化维度 | 情绪对应 |
|------|----------|----------|
| **大小** | 大颗粒（重击/钝器）→ 小颗粒（切割/穿刺）→ 粉尘（能量消散） | 越大越重，越小越锐利 |
| **数量** | 密集（爆发/终结）→ 稀疏（试探/轻击） | 越多越激烈 |
| **运动** | 向外飞散（爆发）→ 向下坠落（消散）→ 悬浮（残留） | 飞散=力量，坠落=结束，悬浮=余韵 |

#### 2. 六种核心粒子/碎片

| 粒子类型 | 形态描述 | 什么时候出现 | 情绪效果 |
|----------|----------|-------------|----------|
| **碰撞火花** | 金属碰撞瞬间产生的细小光点，呈扇形飞散 | 武器格挡、砍中铠甲 | 让观众“看到”碰撞的力度 |
| **能量碎片** | 光效碎裂后的块状光片，旋转着飞出去，然后消散 | 能量护盾被破、光效被击碎 | 让观众“看到”防御被打破 |
| **铠甲碎片** | 金属/铠甲被击碎后的实体碎片，有重量感，落地有声音 | 重击命中、护甲被破 | 让观众“看到”防御被物理破坏 |
| **布料/衣摆碎片** | 衣物被割裂后的布条，在空中飘动 | 切割类武器命中 | 让观众“看到”攻击的锋利 |
| **血液/能量液** | 红色血液或金色能量液，从伤口喷出或滴落 | 穿刺/切割命中 | 让观众“看到”受伤的真实感 |
| **环境碎石** | 地面/墙壁被击碎后的石块、尘土 | 重击落地、撞墙、砸地 | 让观众“看到”环境被破坏 |

#### 3. 不同情绪的粒子特征

| 情绪 | 粒子类型偏好 | 粒子大小 | 粒子数量 | 运动特征 |
|------|-------------|----------|----------|----------|
| **悲壮** | 能量碎片 + 血液/能量液 | 中等 | 中等 | 缓慢飞散，像花瓣飘落 |
| **愤怒** | 碰撞火花 + 铠甲碎片 + 环境碎石 | 大 | 密集 | 剧烈飞散，向各个方向喷射 |
| **优雅** | 能量碎片 + 布料碎片 | 小 | 稀疏 | 均匀扩散，像花瓣飘落 |
| **绝望** | 血液/能量液 + 能量碎片（暗淡） | 小 | 稀疏 | 向下坠落，没有飞散的力量 |
| **碾压** | 环境碎石 + 铠甲碎片（对方） | 大 | 密集（对方） | 从被碾压者身上爆发 |
| **焦灼** | 碰撞火花（频繁但小规模） | 小 | 稀疏但频繁 | 每次碰撞都有，但都不大 |

### 三、碰撞冲击波：按武器和力度分类

#### 1. 冲击波三大属性

| 属性 | 变化维度 | 对应关系 |
|------|----------|----------|
| **形状** | 环形（标准）→ 扇形（横斩）→ 锥形（突刺）→ 球形（爆炸） | 与攻击方向一致 |
| **速度** | 极快（轻击）→ 中等（重击）→ 缓慢（蓄力） | 越快越轻，越慢越重 |
| **持续时间** | 0.1秒（轻击）→ 0.3秒（重击）→ 0.5秒（大招） | 越长越有力量感 |

#### 2. 六种冲击波

| 冲击波类型 | 形态描述 | 什么时候出现 | 视觉要点 |
|----------|----------|-------------|----------|
| **环形冲击波** | 从碰撞点向外扩散的圆形光环，边缘清晰 | 标准碰撞、格挡 | 扩散速度由快到慢，颜色由亮变暗 |
| **扇形冲击波** | 从碰撞点向攻击方向扩散的扇形光幕 | 横斩、横扫 | 扇形角度与攻击角度一致 |
| **锥形冲击波** | 从碰撞点向前方扩散的锥形光柱 | 突刺、直拳 | 锥形尖端在碰撞点，底部在攻击方向 |
| **球形冲击波** | 从碰撞点向所有方向扩散的球形光罩 | 爆炸、大招释放 | 球体膨胀到最大后碎裂消散 |
| **地面冲击波** | 沿地面扩散的环形波纹，带碎石和尘土 | 重击落地、砸地 | 波纹沿地面扩散，所过之处地面龟裂 |
| **空气冲击波** | 透明的空气扭曲波纹（像热浪） | 能量波、远程攻击 | 空气扭曲，背景模糊 |

| **优雅** | 环形冲击波 + 扇形冲击波 | 中等 | 0.3秒 | 淡金，边缘清晰 |
| **绝望** | 无冲击波（攻击无力）或极小环形 | 极慢 | 0.1秒 | 暗金，几乎看不见 |
| **碾压** | 球形冲击波（一次，巨大） | 极快 | 0.5秒 | 亮金，全屏扩散 |
| **焦灼** | 环形冲击波（频繁但小） | 快 | 0.2秒 | 中性金，大小适中 |

## 新增：风格化特效库

### 核心原则
> **风格化特效不是替代基础特效，而是给基础特效穿上一件“外衣”。**

同一套碰撞反应（击中→冲击波→粒子飞散），换上不同的风格化外衣，看起来就是完全不同的打戏。

### 一、风格化特效主题库

#### 1. 法阵

| 属性 | 描述 |
|------|------|
| **一句话感受** | 每一次攻击都是一道阵法 |
| **视觉特征** | 圆形/多边形几何纹路，发光线条，旋转，符文 |
| **适用情绪** | 优雅、悲壮、碾压 |
| **适用角色** | 法师、道士、机关师、上古传承者 |

**具体表现：**

| 特效类型 | 法阵化改造 |

| **蓄力光球** | 光球变成一个小型旋转法阵，符文在法阵边缘流动 |
| **爆发光环** | 光环变成一道展开的巨大法阵，几何纹路从中心向外扩散 |

| **碰撞冲击波** | 冲击波边缘带锯齿状符文，像法阵的边界 |

## AIGC 制作流水线（重构）

### 核心原则
> **流水线不是线性走一遍，而是每个环节都有检查点，发现问题立刻回退修复。**

AI生成的不确定性决定了流水线必须是**循环迭代**的，而不是一次性走完。

```
素材准备 → AI图生视频 → 检查点① → 后期合成 → 检查点② → 成片输出

    |            |            ↓            |            |
    └──── 修复 ──┴──── 重新生成 ──────────┴──── 重新剪辑 ──┘
```

### 二、素材准备

#### 2.1 分工说明

| 工具 | 负责内容 | 输出格式 |
|------|----------|----------|
| **PS（Photoshop）** | 角色抠图、背景分层、调色、关键帧绘制、瑕疵修复 | PNG（带透明通道）、PSD（分层源文件） |
| **Level TV** | 动态素材生成、特效预合成、光效叠加、粒子预渲染 | MP4（带透明通道）、PNG序列 |

#### 2.2 素材清单

| 素材类型 | 数量建议 | 说明 |
|----------|----------|------|
| **角色关键帧** | 每个动作3-5张 | 起手、蓄力、命中、收招、终结，每个阶段一张 |
| **背景分层** | 2-3层 | 远景（虚空/天空）、中景（建筑/环境）、前景（粒子/雾气） |

### 三、AI 图生视频

#### 3.1 工具选择

| 工具 | 适用场景 | 优势 | 劣势 |
|------|----------|------|------|
| **Sedance 2.0** | 角色动作生成、特效动画 | 动作流畅、风格可控 | 容易崩脸、穿模 |
| **Runway Gen-2** | 环境动画、背景动态 | 环境效果好、光影自然 | 角色动作不够精准 |
| **Pika Labs** | 快速原型、测试动作 | 生成速度快 | 画质一般 |
| **Kaiber** | 风格化转场、特效动画 | 风格化强、艺术感好 | 动作连贯性差 |

**推荐组合**：Sedance 2.0（主）+ Runway（辅，用于背景和特效）

#### 3.2 输入输出规范

| 项目 | 说明 |
|------|------|
| **输入** | 关键帧图片（PNG）+ Prompt（动作+镜头+特效+风格） |
| **输出** | 2-5秒视频片段（MP4，24fps） |
| **分辨率** | 1920×1080（1080p）或 3840×2160（4k） |
| **帧率** | 24fps（电影感）或 30fps（流畅感） |

#### 3.3 生成参数建议

| 参数 | 建议值 | 说明 |
|------|--------|------|
| **运动强度** | 0.5-0.8 | 越高动作越大，但容易崩 |
| **一致性** | 0.7-0.9 | 越高越接近关键帧，但动作可能僵硬 |
| **帧数** | 48-120帧（2-5秒） | 太短动作不完整，太长容易崩 |
| **种子值** | 固定 | 同一种子值可复现结果，方便微调 |

#### 3.4 生成策略

| 动作类型 | 生成策略 | 说明 |
|----------|----------|------|
| **单次攻击** | 一张关键帧生成2秒 | 起手→命中，一次生成 |
| **连招** | 分三段生成后拼接 | 起手→中段→终结，每段2秒 |
| **蓄力+爆发** | 两张关键帧生成3秒 | 蓄力（1.5秒）+ 爆发（1.5秒） |
| **慢动作** | 一张关键帧生成2秒，后期变速 | 生成时用正常速度，剪映里放慢 |
| **环境动画** | 一张背景图生成5秒 | 云雾流动、粒子飘浮、光影变化 |

### 五、后期合成

#### 5.1 工具选择

| 工具 | 适用场景 | 优势 |
|------|----------|------|
| **剪映** | 主剪辑、拼接、变速、转场、调色 | 操作简单、模板丰富 |
| **Premiere Pro** | 精细剪辑、多轨道合成 | 专业级控制 |
| **After Effects** | 特效叠加、粒子系统、光效合成 | 特效能力强 |
| **DaVinci Resolve** | 调色、音频处理 | 调色专业级 |

**推荐组合**：剪映（主剪辑）+ AE（特效叠加）

#### 5.2 剪辑流程

| 步骤 | 操作 | 说明 |
|------|------|------|
| **1. 素材导入** | 将所有AI生成片段导入剪映 | 按场景/动作命名，方便查找 |
| **2. 粗剪** | 按脚本顺序拼接片段 | 先不管节奏，只保证故事连贯 |
| **3. 精剪** | 调整每个片段的入点和出点 | 去掉开头和结尾的模糊帧 |
| **4. 变速** | 对关键动作做慢动作/快放 | 慢动作：0.3-0.5倍速；快放：1.5-2倍速 |
| **5. 转场** | 在片段之间添加转场 | 推荐：闪白（爆发）、震动（冲击）、溶解（慢动作） |
| **6. 特效叠加** | 在AE中叠加光效/粒子/冲击波 | 用叠加层增强AI生成不足的特效 |
| **7. 调色** | 统一所有片段的色调 | 套用LUT或手动调整 |
| **8. 音效** | 添加打斗音效 | 金属碰撞、能量爆发、破空声 |
| **9. 输出** | 导出成片 | 推荐：H.264，1080p，24fps |

#### 5.3 变速技巧

| 动作类型 | 变速建议 | 效果 |
|----------|----------|------|
| **蓄力** | 0.5倍速 | 让观众感受到力量在聚集 |
| **攻击命中** | 0.3倍速 | 放大打击感，让观众看清碰撞瞬间 |
| **连招** | 1.2-1.5倍速 | 加快节奏，制造紧迫感 |
| **被击飞** | 0.5倍速 | 让观众看清被击飞的过程 |
| **终结一击** | 0.2倍速+定格 | 最强打击感，定格1-2帧 |

#### 5.4 转场选择

| 转场类型 | 适用场景 | 效果 |
|----------|----------|------|
| **闪白** | 大招爆发、能量爆炸 | 模拟强光闪瞎眼睛的效果 |
| **震动** | 重击命中、冲击波扩散 | 模拟受冲击的视觉震动 |
| **溶解** | 慢动作切换、情绪转换 | 柔和过渡，适合悲壮/优雅 |
| **快速切换** | 连招、攻防转换 | 无转场，直接切，节奏感强 |
| **黑场** | 终结后、角色死亡 | 留白，让观众消化情绪 |

### 六、检查点与容错机制

#### 6.1 检查点设置

| 检查点 | 位置 | 检查内容 | 通过标准 | 失败处理 |
|--------|------|----------|----------|----------|
| **①** | AI生成后 | 画面是否崩坏、动作是否连贯 | 无穿模、无崩脸、动作流畅 | 重新生成或修复关键帧 |
| **②** | 粗剪后 | 故事是否连贯、节奏是否合理 | 情绪曲线正确、无跳跃感 | 调整片段顺序或补拍 |
| **③** | 精剪后 | 打击感是否足够、特效是否到位 | 碰撞有停顿、冲击波明显 | 叠加特效或调整变速 |
| **④** | 调色后 | 色调是否统一、风格是否一致 | 所有片段色调一致 | 重新调色或套用LUT |

#### 6.2 常见翻车与修复

| 翻车类型 | 表现 | 修复方案 |
|----------|------|----------|
| **角色穿模** | 武器穿过身体、角色重叠 | 剪映蒙版遮罩 + 关键帧修补；或PS逐帧抠图 |
| **面部崩坏** | 眼睛/嘴巴畸形、表情诡异 | 局部重绘（Inpainting）→ 切远景/侧脸/特写武器 |
| **闪烁/抖动** | 画面明暗闪烁、角色位置抖动 | 剪映防抖（强度50%）+ 光流补帧（流畅模式） |
| **动作不连贯** | 两段AI生成视频之间动作跳跃 | 中间插入过渡帧（PS绘制或Runway补帧） |
| **背景穿帮** | 背景出现奇怪物体/人物 | 剪映背景模糊/替换背景 + 蒙版 |
| **色彩不一致** | 两段素材色调不同 | 剪映调色统一（套用同一LUT或手动匹配） |

#### 6.3 备用素材库

| 素材类型 | 用途 | 来源建议 |
|----------|------|----------|
| 通用爆炸/冲击波 | 遮盖穿模区域、增强特效 | 剪映素材库、Pexels视频 |
| 粒子/碎片叠加层 | 增加打击感、掩盖画面瑕疵 | AE模板、Motion Array |
| 黑色遮罩/光晕 | 转场、遮挡崩坏区域 | PS自制 |
| 音效包（通用） | 后期配音 | Freesound、Zapsplat |

## 声音设计（完整版）

### 核心原则
> **打戏的一半灵魂在声音。观众通过声音感受到力度、速度和情绪。**

AI生成的视频默认是无声的，声音需要后期手动匹配。好的声音设计能让画面冲击力翻倍。

### 二、节奏匹配规则

#### 2.1 动作阶段与音效处理

| 动作阶段 | 音效处理 | 示例 |
|----------|----------|------|
| **慢动作** | 音效拉长（时间拉伸）+ 加重混响 + 降低高频 | 刀剑碰撞瞬间，金属声拉长至1.5秒，带空间回响 |
| **快节奏连招** | 音效密集叠加，每0.2-0.3秒一个命中音，不重叠 | 轻击×3：铛铛铛，每个音效0.1秒，间隔0.1秒 |
| **蓄力阶段** | 低频嗡鸣渐强，音量从20%升至80%，持续1-2秒 | 剑尖聚集金色能量，嗡鸣声随光球变大而增强 |
| **爆发瞬间** | 前0.1秒静音 → 瞬间巨响（冲击波+金属碰撞+玻璃碎裂混合） | 大招释放，全频段爆裂，持续0.5秒后快速衰减 |
| **终结定格** | 所有音效骤停 → 0.5秒静默 → 一声沉重金属回响（带尾音） | 最后一刀命中，画面定格，音效回响2秒后淡出 |
| **对峙阶段** | 只有环境音（风声/嗡鸣）+ 心跳声（渐快） | 双方互相环绕，心跳声随紧张感加速 |

#### 2.2 力度分级

| 力度等级 | 音效特征 | 适用场景 |
|----------|----------|----------|
| **轻击** | 短促、高频、音量低 | 试探攻击、快速连招中的前几击 |
| **中击** | 中等时长、中频、音量中等 | 普通攻击、格挡 |
| **重击** | 较长、低频为主、音量高 | 蓄力攻击、终结技 |
| **大招** | 极长、全频段、音量极高+静默对比 | 终极技能、爆发 |

## 视觉风格基座（重构版）

### 核心原则
> **不是名词堆砌，而是感官描述。让读的人脑子里有画面、有感受、知道怎么做。**

---

### 一、核心感受一句话

> **“在宇宙深渊里，两位仙人用光在战斗。”**

---

### 二、分维度感官描述

#### 2.1 空间感：不是“暗黑深空”，而是“有重量的虚空”

| 维度 | 描述 |
|------|------|
| **颜色** | 背景不是纯黑，而是深到发蓝的宇宙底色，像深夜仰望没有星星的天空 |
| **深度** | 远处有微弱的星点或尘埃漂浮，让人感觉空间是无限的、有深度的 |
| **地面** | 角色站在虚无之上，脚下没有地面，但有能量涟漪随着脚步扩散，暗示“这里是有实体的虚空” |
| **感受** | 压抑、孤独、宏大，像在太空站窗外看无尽黑暗 |

#### 2.2 光效：不是“金色能量”，而是“有温度的光”

| 维度 | 描述 |
|------|------|
| **颜色** | 金色不是亮黄色，而是熔岩般的橙金，像铁水在流动 |
| **质感** | 光效不是均匀发光，而是从内部燃烧出来的——中心炽白，边缘橙红，最外层是暗金色余晖 |
| **轨迹** | 光在空气中留下残影，像用燃烧的树枝在空中写字，轨迹会停留0.3秒才消散 |
| **照明** | 光打在角色脸上时，半边脸被照亮，半边脸沉入黑暗，形成强烈的明暗对比 |
| **感受** | 炽热、危险、神圣，像触碰就会被灼伤 |

#### 2.3 材质：不是“赛博仙侠”，而是“古老与未来的碰撞”

| 维度 | 描述 |
|------|------|
| **武器** | 剑身是古代青铜器的质感，但表面有流动的霓虹纹路，像电路板嵌入青铜 |
| **铠甲** | 硬表面+布料——肩甲是金属（有磨损划痕），衣摆是丝绸（在虚空中缓慢飘动） |
| **皮肤** | 角色皮肤上有隐约的金色纹路（像经脉发光），但不是纹身，而是能量在体内流动的视觉效果 |
| **环境** | 破碎的石柱/古建筑漂浮在虚空中，石头上长着发光的晶体，像赛博朋克版的敦煌 |
| **感受** | 既古老又未来，像千年后的考古学家挖出了外星文明 |

#### 2.4 动态：不是“打戏”，而是“光的舞蹈”

| 维度 | 描述 |
|------|------|
| **轨迹** | 每次挥剑，金色光轨在黑暗中划出一道弧线，像书法的一笔 |
| **爆发** | 能量爆发时，不是爆炸，而是光从一点向外绽放，像花朵开放的时间加速版 |
| **慢动作** | 慢动作时，光在空气中缓慢流动，像蜂蜜滴落 |
| **瞬移** | 角色瞬移时，原地留下金色残影（持续0.5秒消散），像烧尽的纸灰 |
| **感受** | 优雅、致命、每一帧都可以截图当壁纸 |

---

### 三、风格描述公式

以后写任何风格描述，都遵循这个公式：

> **不是 [名词]，而是 [感官体验 + 具体细节 + 引发的感受]**

**示例：**

| ❌ 原版 | ✅ 重构版 |
|---------|----------|
| 暗黑深空 | 像深夜仰望没有星星的天空，脚下有能量涟漪扩散，让人感到孤独和宏大 |
| 金色能量 | 像熔岩从内部燃烧出来，中心炽白边缘橙红，在空气中留下0.3秒的残影 |
| 赛博仙侠 | 青铜剑身嵌入霓虹纹路，古建筑碎片漂浮在虚空中，石头上长出发光晶体 |
