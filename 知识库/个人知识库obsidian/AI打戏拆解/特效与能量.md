
## 风格化特效库

### 核心原则
> **风格化特效不是替代基础特效，而是给基础特效穿上一件“外衣”。**

同一套碰撞反应（击中→冲击波→粒子飞散），换上不同的风格化外衣，看起来就是完全不同的打戏。

---

### 一、法阵

| 属性 | 描述 |
|------|------|
| **一句话感受** | 每一次攻击都是一道阵法 |
| **视觉特征** | 圆形/多边形几何纹路，发光线条，旋转，符文 |
| **适用情绪** | 优雅、悲壮、碾压 |
| **适用角色** | 法师、道士、机关师、上古传承者 |

| 特效类型 | 法阵化改造 |
|----------|-----------|
| **蓄力光球** | 光球变成一个小型旋转法阵，符文在法阵边缘流动 |
| **爆发光环** | 光环变成一道展开的巨大法阵，几何纹路从中心向外扩散 |
| **轨迹光线** | 挥剑轨迹变成一道发光的符文链，像在空中写咒语 |
| **碰撞冲击波** | 冲击波边缘带锯齿状符文，像法阵的边界 |
| **武器附魔** | 武器表面浮现细小的旋转法阵，层层叠加 |
| **能量残留** | 伤口处留下一个微缩法阵，缓慢旋转后消散 |
| **粒子碎片** | 碎片变成破碎的符文光点，像烧焦的纸灰飘落 |

### 二、水墨

| 属性 | 描述 |
|------|------|
| **一句话感受** | 打戏是一幅流动的水墨画 |
| **视觉特征** | 黑白为主，少量留白，墨迹飞溅，笔触感，晕染效果 |
| **适用情绪** | 优雅、悲壮、绝望 |
| **适用角色** | 隐士、剑客、画师、古代武者 |

| 特效类型 | 水墨化改造 |
|----------|-----------|
| **蓄力光球** | 光球变成一团旋转的墨汁，边缘有晕染效果 |
| **爆发光环** | 光环变成一圈墨迹扩散，像毛笔在宣纸上画了一个圈 |
| **轨迹光线** | 挥剑轨迹变成一道墨线，有笔锋（起笔重、收笔轻） |
| **碰撞冲击波** | 冲击波变成墨汁飞溅，像一滴墨掉进水里的扩散效果 |
| **武器附魔** | 武器表面有墨色流动，像被墨水浸染 |
| **能量残留** | 伤口处留下一道墨痕，像书法的一笔 |
| **粒子碎片** | 碎片变成墨点飞溅，大小不一，像甩笔的效果 |

**色彩处理**：不是完全黑白，而是低饱和度+墨色为主，金色能量变成金色墨汁。

## 剑术动作库

在「风格化特效库」之后新增一个「剑术动作库」章节，作为特效的**动作基础层**：

### 剑术 vs 刀术 核心动作对照

|维度|剑术|刀术|
|---|---|---|
|**核心动作**|刺、点、挑、撩、抹|砍、劈、斩、扫|
|**发力方式**|腕变刃刺，以柔克刚|腰带臂砍，刚猛霸道|
|**运动轨迹**|线性+弧线（轻灵）|大弧线（沉重）|
|**节奏感**|快、准、飘|猛、重、沉|
|**气质**|君子、潇洒、飘逸|粗豪、霸道、刚猛|

### 剑术 Prompt 动词库

|动词|含义|适用场景|
|---|---|---|
|`thrust`|突刺|剑法核心，致命一击|
|`flick wrist`|腕部弹抖|点刺、变招|
|`lift blade`|撩剑上挑|破防、反击|
|`graze`|抹剑滑切|轻伤、试探|
|`tap`|点剑|精准打击要害|
|`parry`|格挡|防御、反击铺垫|
|`withdraw`|收剑|洒脱感、余韵|

**避免的词汇**：`hack`（砍）、`swing wildly`（疯狂挥舞）、`heavy`（沉重）、`brute force`（蛮力）

## 力度感的三重打击结构

### 力度感 = 后果，不是接触

|片段|时长|内容|Prompt 重点|
|---|---|---|---|
|**A：蓄力**|2-3s|微沉重心，剑尖微颤，空气凝滞|`charging energy, blade tip vibrating, air pressure building`|
|**B：接触**|0.5-1s|极快刺击，刚接触就切|`lightning fast thrust, blade flash, motion blur`|
|**C：后果**|3-5s|对手飞出/武器脱落/地面裂纹|`opponent thrown backward, ground cracking, shockwave ring`|

> **核心原则**：B 越短越有力量感。观众觉得"疼"，是因为看了"后果"，而不是"接触"本身。
