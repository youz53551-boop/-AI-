## 碰撞反应系统 

### 一、按命中部位分类

|命中部位|反应|后续效果|视觉表现|
|---|---|---|---|
|**头部**|头部后仰 + 身体跟随后退|短暂眩晕（0.5秒内动作迟缓）|头发/头盔碎片飞溅，金色火星|
|**肩膀/上臂**|身体向一侧倾斜 + 脚步踉跄|该侧手臂暂时下垂（无法格挡下一击）|肩甲碎片脱落，布料撕裂|
|**胸口/躯干**|整个身体弓起 + 双脚离地少许|后退3-5步，呼吸急促（胸口起伏明显）|衣服上留下灼烧痕迹，能量残留|
|**腹部**|身体折叠（弯腰）+ 跪地|短暂失去战斗能力（1-2秒内无法起身）|口中溢出金色光点（类似吐血）|
|**腿部**|单腿弯曲 + 身体下蹲|移动速度下降，跛行|腿部护甲碎裂，能量从裂口泄漏|
|**武器**|武器脱手 + 旋转飞出|角色空手，需要重新召武器或捡起|武器在空中旋转，拖出金色光轨|

### 二、按攻击方向分类

|攻击方向|反应|视觉表现|
|---|---|---|
|**正面直刺**|身体向后弓起 + 双脚擦地后退|胸口能量爆裂，冲击波从背后扩散|
|**侧面横斩**|身体向反侧倾斜 + 旋转半圈|腰部/肋部光效迸发，身体旋转时带出金色弧线|
|**上挑**|身体浮空 + 四肢张开|脚下冲击波，身体腾空0.5-1秒后重重落地|
|**下劈**|身体下蹲 + 单膝跪地 + 地面裂开|肩膀/头部承受冲击，地面以落脚点为中心龟裂|
|**背后攻击**|身体前扑 + 翻滚落地|背部光效爆裂，前扑时武器脱手|
|**从上方攻击**|身体被压向地面 + 四肢贴地|地面凹陷，周围碎石飞起|

### 三、按武器类型分类

|武器类型|命中反应特征|特殊效果|
|---|---|---|
|**剑/刀（切割）**|伤口处先出现一条细线，0.1秒后鲜血/能量喷涌|衣物/皮肤上有整齐切口，边缘发光|
|**锤/棍（钝击）**|命中处凹陷 + 身体整体位移|不流血，但骨骼变形（铠甲凹陷），内伤表现为嘴角溢血|
|**枪/矛（穿刺）**|身体被贯穿 + 钉在原地0.3秒|贯穿处有能量残留，拔出时带出光点|
|**能量波（冲击）**|身体被推飞 + 空中旋转多圈|全身被能量包裹，落地后滑行一段距离|
|**暗器/飞镖**|身体局部抽搐 + 伸手去拔|命中处有细小光点，拔除时带出血丝|

### 四、按双方状态分类

|攻击者状态|被攻击者状态|反应变化|
|---|---|---|
|**满血/全力**|满血/满防|标准反应（如上表）|
|**满血/全力**|残血/残防|反应放大：击飞距离翻倍，倒地后无法立即起身|
|**残血/虚弱**|满血/满防|反应缩小：仅轻微后仰，被攻击者几乎不受影响|
|**蓄力攻击**|任何状态|反应增强：命中时画面定格1-2帧，冲击波范围扩大|
|**仓促攻击**|任何状态|反应减弱：被攻击者仅后退半步，立刻反击|

### 五、连续命中反应链

当同一角色在短时间内被连续命中时，反应应该**逐级加重**：

|连击次数|反应|视觉表现|
|---|---|---|
|第1击|后仰 + 后退1步|轻微火花|
|第2击|身体倾斜 + 后退2步|火花变大，衣物破损|
|第3击|单膝跪地 + 武器撑地|能量从伤口泄漏|
|第4击|击飞 + 空中旋转|全身光效爆裂，空中拖出光轨|
|第5击（终结）|撞墙/倒地 + 武器脱手|全屏冲击波，地面龟裂，角色陷入地面|

### 六、环境交互反应

被击中的角色不应该只停留在原地，应该与**环境产生互动**：

|环境类型|碰撞反应|
|---|---|
|**地面**|滑行一段距离（留下两道划痕），或砸出一个人形坑|
|**墙壁**|撞墙后墙面龟裂，身体贴墙滑落，墙上留下能量残留|
|**柱子/岩石**|撞断柱子/撞碎岩石，碎石飞溅，角色被埋在碎石下|
|**水面**|在水面滑行（激起水花），或沉入水中（气泡上涌）|
|**虚空/空中**|空中翻滚多圈后稳住身形，或坠落一段距离后重新悬浮|

### 七、反应时间线（以一次重击为例）

```
T+0.00s：武器接触身体（接触帧停顿1-2帧）
T+0.02s：冲击波从接触点扩散（环形金色光效）
T+0.05s：身体开始变形（凹陷/弯曲/撕裂）
T+0.10s：身体被击飞（双脚离地）
T+0.15s：空中旋转（衣物/头发飘动，光效拖尾）
T+0.30s：撞墙/落地（第二次冲击波，地面龟裂）
T+0.50s：滑落/静止（身体抽搐一下，然后不动）
T+1.00s：能量残留消散（伤口处光点慢慢熄灭）
```

## 如何应用到你的知识库

在 **动作编排** 模块下，新增一个子模块：

```
### 碰撞反应系统
- 按命中部位：头部/肩膀/胸口/腹部/腿部/武器
- 按攻击方向：正面/侧面/上挑/下劈/背后/上方
- 按武器类型：切割/钝击/穿刺/冲击/暗器
- 按双方状态：满血/残血/蓄力/仓促
- 连续命中反应链：第1击→第5击逐级加重
- 环境交互：地面/墙壁/柱子/水面/虚空
- 反应时间线：接触→冲击波→变形→击飞→落地→残留
```

这样，每次设计打戏时，你只需要回答三个问题：

1. **打中哪里？**（部位）
2. **怎么打的？**（方向+武器）
3. **双方什么状态？**（满血/残血）
