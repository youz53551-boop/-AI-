
## 动作编排
### 核心原则
> **动作不是招式堆砌，而是角色情绪和战斗意图的外化。**

每一次攻击、每一次防御、每一次走位，都应该让观众看懂角色**想干什么**——是想杀死对方、逼退对方、还是拖延时间。

---

### 一、攻击/防御模式：按战斗意图分类

#### 1. 攻击意图

| 攻击类型   | 动作特征                | 什么时候用           | 情绪效果  |
| ------ | ------------------- | --------------- | ----- |
| **试探** | 快速、幅度小、收招快（刺一下立刻收回） | 开局、面对未知对手、寻找破绽  | 谨慎、冷静 |
| **压制** | 连续、密集、不追求命中率（逼对方走位） | 占据优势时、想把对方逼到角落  | 强势、侵略 |
| **致命** | 蓄力、大幅度的终结一击（赌上一切）   | 确定破绽时、最后一击、同归于尽 | 决绝、危险 |
| **牵制** | 攻击不指向身体，指向对方下一步位置   | 阻止对方靠近/逃跑/施法    | 控制、算计 |
| **泄愤** | 无章法、大开大合、不计体力       | 愤怒、失去理智、被激怒     | 狂暴、混乱 |

#### 2. 防御意图

| 防御类型 | 动作特征 | 什么时候用 | 情绪效果 |
|----------|----------|-----------|----------|
| **硬抗** | 武器/手臂正面格挡，不退 | 不能退的时候（身后有人/悬崖） | 坚决、悲壮 |
| **卸力** | 格挡同时后退/侧身，让攻击滑开 | 面对重击、想保存体力 | 技巧、从容 |
| **闪避** | 完全躲开攻击（侧翻/后跳/瞬移） | 面对无法格挡的攻击、寻找反击机会 | 灵活、冷静 |
| **弹反** | 在攻击命中的瞬间格挡，触发反击 | 高手对决、想快速结束战斗 | 精准、自信 |
| **逃跑** | 转身就跑/飞走 | 打不过、战略性撤退 | 狼狈、务实 |

#### 3. 攻防转换逻辑

```
攻击命中 → 继续压制（连招）
攻击被格挡 → 收招防守（防止反击）
攻击落空 → 立刻闪避（防止被抓住硬直）
防御成功 → 立刻反击（弹反/格挡后反击）
防御被破 → 紧急闪避/硬吃下一击
```

### 二、连招组合设计：按情绪基调定制

#### 1. 悲壮连招

```
动作特征：慢、重、每一击都像最后一击
节奏：蓄力（1秒）→ 重击 → 停顿（喘息）→ 蓄力 → 重击
走位：直线推进（不退，每一步都向前）
连招模板：
  蓄力横斩（逼退敌人）→ 停顿（胸口起伏）→ 蓄力上挑（击飞）→ 追击（空中抱住敌人一起坠落）
情绪目的：让观众感受到“他在燃烧自己”
```

#### 2. 愤怒连招

```
动作特征：快、乱、不计后果
节奏：连续攻击（无停顿）→ 被格挡 → 更疯狂地攻击
走位：直线冲刺（不绕后，正面硬刚）
连招模板：
  突刺×3（压制）→ 横斩（被格挡）→ 怒吼 → 乱舞（无章法连续挥砍）→ 蓄力重击（终结）
情绪目的：让观众感受到“他失控了”
```

#### 3. 优雅连招

```
动作特征：流畅、精准、每一击都有预留后手
节奏：攻击（0.3秒）→ 收招（0.2秒）→ 观察 → 攻击
走位：弧线走位（绕后/侧击，不与对方正面硬拼）
连招模板：
  侧步 → 刺手腕（缴械）→ 转身 → 横斩腰部 → 收招（剑尖下垂）→ 等待对方反应
情绪目的：让观众感受到“他在戏弄对手”
```

#### 4. 绝望连招

```
动作特征：无力、挣扎、被中断
节奏：攻击 → 被格挡/闪避 → 被反击 → 倒地 → 爬起来 → 再攻击
走位：后退为主（被逼退），偶尔前冲（被击退）
连招模板：
  突刺（被闪避）→ 被击中 → 后退 → 蓄力（被中断）→ 被击飞 → 爬行（试图够武器）
情绪目的：让观众感受到“他赢不了”
```

#### 5. 碾压连招

```
动作特征：极简、随意、一招就够了
节奏：静止（等待对方攻击）→ 随手一击 → 看对方飞出去
走位：几乎不走位（站在原地）
连招模板：
  不动（等对方冲过来）→ 侧身（闪避）→ 随手一挥（击中）→ 转身（不看结果）
情绪目的：让观众感受到“他根本没认真”
```

#### 6. 焦灼连招

```
动作特征：攻防转换极快、每一招都被化解
节奏：攻击 → 被格挡 → 立刻防守 → 对方攻击 → 格挡 → 立刻反击
走位：互相环绕（都在找破绽，都不轻易出手）
连招模板：
  刺（被格挡）→ 收招格挡（对方反击）→ 弹反 → 对方闪避 → 双方拉开 → 重新对峙
情绪目的：让观众感受到“谁先失误谁死”
```

### 三、节奏与呼吸：不是线性，是波浪形

#### 1. 节奏波浪模型

```
情绪强度
  ^
  |     /\        /\        /\
  |    /  \      /  \      /  \
  |   /    \    /    \    /    \
  |  /      \  /      \  /      \
  | /        \/        \/        \
  +----------------------------------> 时间
    波峰      波谷      波峰      波谷
```

- **波峰**：攻击密集、速度快、情绪高
- **波谷**：对峙、喘息、蓄力、情绪回落

#### 2. 不同情绪的波浪特征

| 情绪 | 波浪特征 | 波峰持续时间 | 波谷持续时间 |
|------|----------|-------------|-------------|
| **悲壮** | 波峰短而高，波谷长而沉 | 1-2秒 | 3-5秒（喘息/对视） |
| **愤怒** | 波峰长而密，几乎没有波谷 | 5-10秒连续攻击 | 0.5-1秒（怒吼后继续） |
| **优雅** | 波峰低而平，波谷从容 | 0.5-1秒（一次攻击） | 1-2秒（收招/观察） |
| **绝望** | 波峰被强行打断，波谷是被击倒 | 0.3-0.5秒（攻击被中断） | 2-4秒（倒地/爬起） |
| **碾压** | 只有一个波峰，然后结束 | 0.5秒（一招） | 无波谷（直接结束） |
| **焦灼** | 波峰波谷交替极快，幅度小 | 0.3-0.5秒（一次攻防） | 0.3-0.5秒（立刻反击） |

#### 3. 呼吸点设计

在波谷位置插入“呼吸点”，让观众和角色一起喘息：

| 呼吸点类型 | 表现 | 适用情绪 |
|-----------|------|----------|
| **对视** | 双方停下，互相盯着对方，镜头给到眼神 | 焦灼、悲壮 |
| **喘息** | 角色弯腰/扶膝，大口喘气，胸口起伏 | 愤怒（发泄后）、绝望 |
| **蓄力** | 能量聚集，光效变亮，镜头推近 | 悲壮、优雅 |
| **环境** | 镜头切到周围环境（破碎的建筑/飘落的尘埃） | 悲壮、绝望 |
| **对话** | 角色说一句话（“你变弱了”/“到此为止了”） | 碾压、优雅 |

### 四、角色空间走位：走位即意图

#### 1. 走位类型与意图

| 走位类型 | 动作特征 | 意图 | 适用情绪 |
|----------|----------|------|----------|
| **直线推进** | 正面冲向对方，不躲不闪 | 压制、拼命、同归于尽 | 愤怒、悲壮 |
| **直线后退** | 正面面对对方，向后移动 | 防守、引诱（让对方追） | 焦灼、优雅 |
| **弧线绕后** | 侧向移动，绕到对方侧面/背后 | 寻找破绽、避开正面 | 优雅、焦灼 |
| **横向闪避** | 向左右快速侧移 | 躲避攻击、重新调整位置 | 焦灼、绝望 |
| **垂直腾空** | 跳起/飞起 | 躲避地面攻击、从上往下攻击 | 优雅、愤怒 |
| **垂直下落** | 快速落地/下坠 | 躲避空中攻击、砸地攻击 | 愤怒、碾压 |
| **瞬移/闪现** | 瞬间出现在另一个位置 | 突袭、逃跑、戏弄对手 | 优雅、碾压 |
| **环绕** | 以对方为中心做圆周运动 | 观察、施压、不让对方休息 | 焦灼、优雅 |

#### 2. 走位组合示例

```
愤怒：直线推进 → 被格挡 → 直线推进（不换方向，硬破防）
优雅：弧线绕后 → 攻击 → 后退（拉开距离）→ 弧线绕另一侧
焦灼：横向闪避 → 直线推进（反击）→ 被格挡 → 横向闪避（退回安全距离）
绝望：直线后退 → 被追上 → 横向翻滚 → 爬起来 → 直线后退
```

#### 3. 走位与镜头配合

| 走位 | 推荐运镜 | 效果 |
|------|----------|------|
| 直线推进 | 跟随（从背后/侧面跟拍） | 让观众感受冲刺的速度感 |
| 弧线绕后 | 环绕（以被绕者为中心） | 让观众看清绕后的轨迹 |
| 瞬移 | 快速切换（原地→出现位置） | 强调“瞬间消失又出现”的突兀感 |
| 垂直腾空 | 上仰（从下往上拍） | 让角色显得高大、有压迫感 |

---

### 总结：动作编排一句话

> **攻击是意图，防御是态度，连招是性格，节奏是情绪，走位是策略。**

五个要素不是独立工作的，而是**同时配合**。例如：

- **悲壮打戏**：蓄力重击（攻击）+ 硬抗（防御）+ 直线推进（走位）+ 慢节奏（呼吸）+ 每一击都像最后一击（连招）
- **优雅打戏**：刺手腕（攻击）+ 卸力（防御）+ 弧线绕后（走位）+ 快慢交替（节奏）+ 行云流水（连招）
